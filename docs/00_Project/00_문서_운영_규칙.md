# 문서 운영 규칙

## Source of Truth

- 최초 원문은 [[pilot]]이다.
- 세부 문서는 [[pilot]]에서 분리한 내용을 구현 단위별로 재정리한다.
- 세부 문서가 [[pilot]]과 충돌하면 구현하지 않고 충돌 내용을 먼저 확정한다.
- 구현 확정 문서는 각 세부 문서의 결정 내용을 모은 뒤 별도 승인으로 고정한다.

## 문서 상태

| 상태 | 의미 |
|---|---|
| draft | 초안. 구현 기준으로 사용하지 않는다. |
| needs-decision | 구현 전 결정이 필요한 항목이 남아 있다. |
| confirmed | 해당 문서의 설계 방향이 승인되었다. |
| implementation-ready | 구현 착수 기준으로 승인되었다. |

## 작성 규칙

- 문서는 Obsidian 링크를 우선 사용한다.
- 구현 확정 전에는 미정 항목을 숨기지 않는다.
- 추정으로 요구사항을 채우지 않는다.
- 미정 항목은 [[01_MVP/04_MVP_확정_필요_항목]]에 모은다.
- `99_*_구현_확정` 문서는 승인 전까지 `needs-decision` 상태를 유지한다.
