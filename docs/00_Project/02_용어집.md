# 용어집

| 용어 | 의미 |
|---|---|
| 생존자 | 플레이어 캐릭터. 저주에 걸린 상태로 의식 결투를 진행한다. |
| 괴이 | AI 스토리 모드에서 상대하는 초자연적 존재. |
| 의식 결투 | 턴마다 행동을 비공개 선택하고 동시에 공개하는 핵심 전투 흐름. |
| 진명 조각 | AI 스토리 모드 승리를 위해 확보해야 하는 핵심 단서. |
| 봉인 | 진명 조각 3개 확보 후 사용할 수 있는 AI 스토리 특수 행동. |
| 이성 | 0이 되면 패배하는 기본 생존 자원. |
| 의식력 | 행동 비용으로 사용하는 자원. |
| 저주 흔적 | 강한 실패나 괴이 공격으로 증가하는 위험 누적치. |
| 비밀 노출도 | 과거 PvP 검토안의 자원. 현재 PvP 미사용 결정에 따라 구현 기준이 아니다. |
| KAG | 세계관 관계를 명시적으로 관리하는 지식 그래프. |
| RAG | 검색된 문서를 바탕으로 LLM 생성을 제한하는 검색 증강 생성 구조. |
| LLM adapter | provider 교체 가능성을 열어두는 LLM 호출 인터페이스. |
