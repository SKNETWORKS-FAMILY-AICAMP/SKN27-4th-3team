# 세계관 프론트 결정 전 검토안

이 문서는 프론트엔드 구현자가 화면, 카피, 사건 데이터, 상태 표시, 결과 화면을 설계할 때 검토할 세계관 후보안이다.

현재 문서는 확정된 세계관 가이드가 아니다. 프론트엔드팀은 이 문서를 논의용 참고안으로 보고, 사용자가 승인한 항목만 공식 기준으로 옮긴다.

## 핵심 정체성

`pilot`은 초자연 공포 스릴러 미스터리 기반 1대1 턴제 심리전 웹 게임이다.

플레이어는 괴이를 공격해서 죽이는 사람이 아니라, 저주받은 생존자로서 괴이와 마주 앉아 진명을 파헤치고 봉인한다.

## 핵심 한 줄

저주받은 생존자가 괴이와 마주 앉아, 심문, 의식, 속임수, 계약으로 괴이의 진명을 파헤치고 살아남는 1대1 심리전 게임.

## 프론트 톤

프론트는 카드 배틀 UI보다 `생존 의식 테이블`에 가깝게 설계한다.

검토할 감각:

- 조사 기록, 낡은 의식 도구, 거울, 봉인지, 촛불, 손글씨, 금이 간 표면
- 전투 UI보다 사건 기록/의식 진행 UI
- 숫자 게이지만 나열하지 않고, 상태가 시각적으로 무너지는 느낌
- 버튼은 카드라기보다 의식 도구를 선택하는 느낌
- 결과 화면은 승패 팝업보다 사건 파일이 닫히거나 오염되는 느낌

피해야 할 감각:

- 화려한 판타지 스킬 버튼
- 슬롯머신, 보상 뽑기, 사행성처럼 보이는 연출
- LLM 채팅 게임처럼 보이는 자유 대화 중심 화면
- PvP 랭크 게임처럼 보이는 전투 중심 UI

## MVP 화면에서 필요한 서사 단위

프론트 MVP는 최소한 아래 서사 단위를 표시할 수 있어야 한다.

| 단위 | 표시 위치 예시 | 설명 |
|---|---|---|
| 사건 제목 | 사건 선택, 브리핑, 결투 상단 | 플레이어가 어떤 괴이 사건에 들어가는지 알려준다. |
| 괴이 가칭 | 브리핑, 결투 화면 | 진명이 아니라 사건 파일상의 임시 이름이다. |
| 금기 | 브리핑, 결투 보조 패널 | 플레이어가 피해야 하는 행동 규칙이다. |
| 진명 조각 | 단서 패널, 결과 화면 | 봉인 조건을 채우는 진짜 단서다. |
| 거짓 단서 | 단서 패널, 결과 화면 | 단서처럼 보이지만 봉인에는 도움이 되지 않는다. |
| 공개 로그 | 턴 결과 영역 | 서버 판정 결과를 짧게 설명한다. |
| 결과 기록 | 결과 화면 | 사건이 어떻게 끝났는지 보여주는 정적 문장이다. |

## 첫 MVP 괴이

1차 MVP에서 실제 구현 대상은 `거울 속의 손님` 1종이다.

`우물 밑의 목소리`, `문밖의 어머니`는 문서와 콘셉트 보존 대상이지만 1차 MVP 구현 대상이 아니다.

## 거울 속의 손님

### 컨셉

거울을 통해 사람의 기억을 훔치는 괴이.

플레이어는 거울 앞의 의식장에서 괴이와 마주 앉는다. 괴이는 플레이어의 기억과 사건 기록을 흐리게 만들고, 진짜 단서와 거짓 단서를 섞어 봉인을 방해한다.

### 사건 가칭

`거울 속의 손님`

### 금기

같은 질문을 두 번 반복하면 안 된다.

프론트 표기 방향:

- 금기는 브리핑에서 명확히 보여준다.
- 결투 중에는 항상 노출하거나, 보조 패널에서 다시 확인 가능하게 한다.
- 금기 위반 여부와 효과는 서버 판정 결과를 따른다.

### 진명 조각

아래 3개는 봉인 조건을 채우는 진짜 단서다.

1. 깨진 거울의 뒷면에 남은 이름
2. 사라진 아이의 마지막 목소리
3. 플레이어가 잊어버린 자기 방 번호

프론트 표기 방향:

- 획득 전에는 빈 슬롯, 흐릿한 봉인지, 깨진 기록 등으로 표시한다.
- 획득 후에는 진짜 단서임을 알 수 있게 고정한다.
- 진짜 단서를 획득했는지 즉시 알려줄지 여부는 아직 확정되지 않았다. 현재 API 명세에서는 `truth_state`로 표현한다.

### 거짓 단서

아래 3개는 거짓 단서 후보로 검토한다.

- 거울을 깨면 끝난다.
- 불을 끄면 안전하다.
- 이름을 부르면 괴이가 약해진다.

프론트 표기 방향:

- 처음부터 거짓이라고 표시하지 않는다.
- 서버가 `truth_state: "false_revealed"`로 내려준 뒤에만 거짓으로 표시한다.
- 확정 전에는 진짜 단서와 같은 기록 패널 안에 섞어서 보여줄 수 있다.

## 상태 표시 기준

| 상태 | 프론트 표현 방향 | 서버 권위 |
|---|---|---|
| 이성 | 화면 흔들림, 시야 좁아짐, 기록 오염, 낮은 숫자 보조 표시 | 서버가 현재값과 감소량을 응답한다. |
| 의식력 | 촛불, 의식 도구, 에너지처럼 표시 가능 | 서버가 현재값과 비용 검증 결과를 응답한다. |
| 저주 흔적 | 손목의 붉은 실, 검은 반점, 균열 | 서버가 현재값과 패배 조건을 판단한다. |
| 보호막 | 종이 부적, 보호진, 얇은 막 | 서버가 보유 여부와 발동 여부를 판단한다. |
| 의심 | 렌즈 균열, 노트 여백의 표시, 보조 숫자 | 서버가 누적과 초기화를 판단한다. |
| 진명 조각 | 봉인지/기록 중앙 슬롯 | 서버가 획득 여부를 판단한다. |
| 거짓 단서 | 기록 가장자리, 의심스러운 메모 | 서버가 생성/제거/공개 상태를 판단한다. |

## 행동 표현 기준

행동은 카드보다 의식 도구에 가깝게 표현한다.

| 행동 | 프론트 의미 | 표현 방향 |
|---|---|---|
| 저주 | 직접 압박 | 검은 못, 붉은 실, 균열, 강한 흔들림 |
| 수호 | 방어 | 부적, 종이 인형, 보호진 |
| 간파 | 정보 확인 | 렌즈, 거울 조각, 기록 대조 |
| 속임수 | 거짓 정보 심기 | 뒤집힌 문장, 위조 단서, 흐릿한 메모 |
| 침묵 | 관망과 차단 | 닫힌 입, 꺼진 촛불, 빈 기록 |
| 계약 | 고위험 진척 | 붉은 실, 인장, 대가 문서 |
| 봉인 | 최종 승리 시도 | 봉인지, 진명 문장, 깨지는 거울 |

## 브리핑 초안

아래 문장은 프론트 목업과 첫 구현용 초안이다. 최종 문장 확정 전까지 `draft_story_text`로 취급한다.

> 사건 파일 01. 거울 속의 손님.  
> 오래된 방의 거울은 사람을 비추지 않는다. 잊어버린 기억과 사라진 목소리를 대신 보여준다.  
> 같은 질문을 반복하지 마라. 두 번째 질문은 네가 묻는 것이 아니다.

## 승리 기록 초안

> 세 조각의 이름이 맞물리자 거울 안쪽의 방이 무너졌다.  
> 손님은 마지막으로 네 얼굴을 흉내 냈지만, 봉인지의 글자가 먼저 닫혔다.  
> 사건 파일은 봉인됨으로 기록된다.

## 패배 기록 초안

> 거울은 끝까지 깨지지 않았다.  
> 네가 기억한다고 믿었던 것들이 하나씩 방 안에서 사라졌고, 마지막 기록에는 네 이름 대신 빈칸만 남았다.  
> 사건 파일은 실종으로 보류된다.

## 프론트가 임의로 만들면 안 되는 것

- 승패 판정
- 이성, 의식력, 저주 흔적, 단서 수치
- 행동 비용 검증
- 봉인 가능 여부
- 단서가 진짜인지 거짓인지의 최종 판정
- LLM 생성 문장을 서버 판정처럼 표시하는 것

## 프론트가 자유롭게 설계해도 되는 것

- 레이아웃
- 색, 질감, 아이콘, 애니메이션
- 상태를 시각화하는 방식
- 공개 로그의 표시 위치
- 단서 패널의 접기/펼치기
- 브리핑과 결과 화면의 연출

단, 자유 설계 범위 안에서도 API 응답의 상태와 충돌해서는 안 된다.
