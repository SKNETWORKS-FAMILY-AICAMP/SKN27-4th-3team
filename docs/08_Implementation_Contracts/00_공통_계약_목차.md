# 결정 전 검토안 목차

이 폴더는 프론트엔드, 백엔드, 스토리, LLM/RAG 작업자가 논의할 수 있도록 만든 결정 전 검토안 공간이다.

현재 문서는 구현 착수 기준이 아니다. 아래 내용은 확정값이 아니라 논의 후보이며, 사용자가 승인한 항목만 이후 공식 구현 문서로 옮긴다.

## 사용 원칙

- 모르는 항목은 숨기지 않고 `decision_required`로 표시한다.
- 프론트엔드는 이 문서를 확정 명세가 아니라 논의용 기준 후보로 본다.
- 백엔드는 이 문서를 확정 명세가 아니라 구조 검토용 후보로 본다.
- LLM/RAG의 금지/허용 범위도 최종 승인 전까지는 설계 후보로 본다.
- 공식 구현 확정은 기존 `99_*_구현_확정` 문서가 `implementation-ready`가 될 때 완료된다.
