# 로비와 사건 선택

## 로비

- AI 스토리 모드 진입 버튼을 제공한다.
- PvP는 MVP에서 비활성 또는 숨김 처리한다.
- 프로필과 전적 요약으로 이동할 수 있다.

## 사건 선택

- MVP에서는 첫 사건 `거울 속의 손님`만 제공한다.
- 사건 제목, 요약, 난이도, 상태를 표시한다.
- 선택 시 브리핑 화면으로 이동한다.
