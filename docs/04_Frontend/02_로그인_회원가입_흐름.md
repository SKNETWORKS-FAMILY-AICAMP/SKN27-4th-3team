# 로그인 회원가입 흐름

## MVP 흐름

1. 사용자가 회원가입 화면에서 계정을 생성한다.
2. 사용자가 로그인 화면에서 인증한다.
3. 서버는 access token과 refresh token cookie를 설정한다.
4. 사용자가 로비로 이동한다.
5. 로그아웃 시 서버가 refresh token을 폐기한다.

## 미확정

- 비밀번호 정책
- 비밀번호 재설정 방식
- 개발 환경에서 cookie secure 옵션 처리
