# MVP 사용자 흐름

## 기본 흐름

1. 사용자가 회원가입한다.
2. 사용자가 로그인한다.
3. 사용자가 로비에 진입한다.
4. 사용자가 AI 스토리 모드를 선택한다.
5. 사용자가 첫 사건 `거울 속의 손님`을 선택한다.
6. 서버가 스테이지 진행 상태를 생성한다.
7. 사용자가 브리핑을 확인한다.
8. 의식 결투가 시작된다.
9. 턴마다 사용자가 행동 1개를 선택한다.
10. 서버가 행동 제출을 검증한다.
11. 서버가 괴이 행동을 결정한다.
12. 서버가 양쪽 행동을 동시에 공개하고 결과를 계산한다.
13. 서버가 턴 로그와 상태 변화를 저장한다.
14. 진명 조각 3개 확보 시 봉인 행동이 열린다.
15. 사용자가 봉인을 시도한다.
16. 서버가 승패를 확정한다.
17. 결과 화면에서 승패, 턴 로그, 스타일 지표를 표시한다.

## 실패 흐름

- 이성이 0이 되면 패배한다.
- 저주 흔적이 5인 상태에서 계약 실패 또는 괴이의 저주를 맞으면 패배한다.
- 12턴 안에 진명 조각을 확보하지 못하면 패배한다.

## 봉인 흐름

- 진명 조각 3개를 확보하면 `봉인` 행동이 열린다.
- 봉인은 단일 턴 행동이다.
- 봉인 방해 단계가 0-1이면 봉인이 성공한다.
- 봉인 방해 단계가 2 이상이면 봉인이 실패한다.
- 상세 기준은 [[09_Approved_Contracts/18_게임_규칙_상성표_상태_승패_계약]]을 따른다.

## 연결 종료와 재접속 흐름

- 사용자가 브라우저를 닫거나 네트워크가 끊겨도 즉시 시간초과로 확정하지 않는다.
- 서버 `deadline_at`까지 유효한 행동 제출이 없으면 시간초과로 처리한다.
- 재접속 또는 새로고침 후에는 현재 매치 상태를 다시 조회한다.
