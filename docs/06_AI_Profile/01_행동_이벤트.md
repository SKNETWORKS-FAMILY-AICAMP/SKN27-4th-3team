# 행동 이벤트

## 저장 항목

행동 이벤트는 턴 resolve 시점에 저장한다.

| 필드 | 설명 |
|---|---|
| user_id | 행동한 사용자 ID |
| mode | 매치 모드 |
| match_id | 매치 ID |
| stage_id | 스테이지 ID |
| turn_number | 턴 번호 |
| action_code | 선택 행동 |
| info_target_key | 정보 대상. 없으면 nullable |
| decision_duration_ms | 선택까지 걸린 시간 |
| sanity_before | 선택 당시 이성 |
| ritual_power_before | 선택 당시 의식력 |
| curse_marks_before | 선택 당시 저주 흔적 |
| opponent_action_code | 상대 행동 |
| result_code | 턴 결과 코드 |
| acquired_clue_id | 획득 단서. 없으면 nullable |
| clue_truth_state | 단서가 진짜였는지 여부 |
| match_outcome | 승패. 매치 종료 전이면 nullable |

## 개인정보 삭제

개인정보 삭제 시 행동 이벤트는 삭제한다.

상세 기준은 [[09_Approved_Contracts/17_백엔드_RAG_AI_Profile_구현_계약]]을 따른다.
