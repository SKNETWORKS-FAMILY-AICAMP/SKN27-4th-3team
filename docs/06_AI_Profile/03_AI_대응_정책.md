# AI 대응 정책

## 원칙

- AI 대응은 룰과 패턴 선택 안에서만 사용한다.
- LLM 요약은 보조 데이터로만 저장한다.
- 행동 로그는 RDB에서 재계산 가능해야 한다.
- 스타일 지표는 각 턴 resolve 직후 계산한다.
- 매치 종료 시 최종 재계산을 수행한다.
- 분모가 0인 지표는 `0.0`으로 저장한다.

## 괴이 행동 반영

- `거울 속의 손님`은 3턴 완료 후 4턴째부터 스타일 보정을 반영한다.
- 보정 방식은 [[09_Approved_Contracts/16_거울_속의_손님_괴이_행동_정책]]을 따른다.
- LLM, RAG, embedding, 자유 텍스트 해석으로 괴이 행동을 선택하지 않는다.

## 개인정보 삭제

개인정보 삭제 시 행동 이벤트와 스타일 스냅샷을 삭제한다.

상세 기준은 [[09_Approved_Contracts/17_백엔드_RAG_AI_Profile_구현_계약]]을 따른다.
