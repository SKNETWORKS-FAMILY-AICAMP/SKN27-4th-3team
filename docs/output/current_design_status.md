## 1. 현재 설계 기준

### 1.1 개발 단계 기준

- 1차 MVP는 `AI 스토리 모드: 인간 플레이어 vs 괴이 AI`다.
- 2차 확장은 `PvP 대전: 인간 플레이어 vs 인간 플레이어`다.
- 따라서 지금부터 모든 룰은 `공통 룰 레이어`와 `AI 스토리 전용 레이어`를 분리해서 설계한다.

### 1.2 공통 룰 레이어

AI와 PvP가 모두 재사용할 수 있어야 하는 영역이다.

- 행동 6종: `저주`, `수호`, `간파`, `속임수`, `침묵`, `계약`
- 공통 자원: `이성`, `의식력`, `저주 흔적`
- 공통 상태: `보호막`, `의심`
- 제출 검증: 턴 번호, 비용, 중복 제출, 제한 시간, client nonce
- 공통 상성 결과:
  - 피해
  - 방어
  - 의식력 변화
  - 저주 흔적 변화
  - 보호막 생성/소모
  - 의심 변화
  - 행동 후보 제한
  - 계약 성공/실패
  - 속임수 성공/실패

### 1.3 AI 스토리 전용 레이어

1차 MVP에서 사용하는 괴이/봉인 구조다.

- 괴이
- 진명 조각
- 불완전한 진명 조각
- 거짓 단서
- 봉인
- 봉인 방해 단계
- 거울 파괴/프레임 붕괴
- 거울 응시
- 괴이 행동 정책
- 브리핑/승리/패배 기록

### 1.4 PvP 전용 레이어

2차 확장 대상이다. 지금은 확정하지 않고 연결 여지만 둔다.

- 비밀 노출도
- PvP 전용 최종 행동 후보
- 실시간 WebSocket 대전
- 매칭 대기열
- 상대 연결 종료/재접속
- 항복
- 랭크/전적
- 허위 비밀/미끼 정보

### 1.5 상성표 작성 기준

앞으로 상성표는 아래 세 층으로 작성한다.

| 항목 | 설명 |
|---|---|
| 공통 결과 | AI/PvP 모두 적용 가능한 결과 |
| AI 스토리 결과 | 진명 조각, 거짓 단서, 봉인 등 |
| PvP 확장 메모 | 나중에 비밀 노출도 등으로 연결할 후보. 현재 확정 아님 |

나쁜 표현:

- `계약 성공 = 진명 조각 +1`
- `속임수 성공 = 거짓 단서 +1`
- `봉인 = 기본 행동`

좋은 표현:

- `계약 성공 = 모드별 목표 진척`
- `속임수 성공 = 모드별 정보 오염 또는 판단 교란`
- `봉인 = AI 스토리 전용 최종 행동`

### 1.6 사용 예정 기술

현재 공식 문서의 기술 방향은 아래와 같다. 단, 세부 구현 문서가 아직 `needs-decision` 상태이므로 구현 착수 기준은 아니다.

| 영역 | 예정 기술 | 현재 판단 |
|---|---|---|
| 프론트엔드 | React + TypeScript + Vite | MVP 포함. 의식 결투 화면, 로비, 결과 화면 구현 후보 |
| 백엔드 HTTP API | Django + Django REST Framework | MVP 포함. 인증, 매치, 턴 제출, 결과 조회 담당 |
| 백엔드 실시간 | Django Channels + ASGI | 2차 PvP에서 중요. 1차 AI 모드에서는 필수 아님 |
| RDB | PostgreSQL | MVP 포함. 매치/턴/행동 로그/단서/스타일 지표 저장 |
| 캐시/실시간 보조 | Redis | PvP, 턴 타이머, 임시 락, rate limit 후보. 1차 MVP 적용 범위는 추가 결정 필요 |
| 백그라운드 작업 | Celery + Redis broker | 로그 집계, 스타일 지표 재계산, 후순위 분석 작업 후보 |
| 인증 | JWT access token + refresh token rotation | MVP 포함 방향. 쿠키/body/CSRF 세부는 미정 |
| RAG | PostgreSQL + pgvector | 후순위. 초기 MVP 판정에는 관여하지 않음 |
| KAG | RDB 기반 knowledge graph | 후순위. 초기 MVP 판정에는 관여하지 않음 |
| LLM | LLM provider adapter | 후순위. 대사/요약 보조 가능하지만 전투 판정, 승패, 보상 계산 금지 |

기술 원칙:

- 서버가 게임 상태와 턴 결과의 최종 권위자다.
- `game_rules`는 순수 함수 중심으로 두고, DB/프레임워크에 강하게 묶지 않는다.
- `matches`는 `game_rules`의 결과를 저장한다.
- LLM, RAG, KAG는 룰 판정과 승패를 바꾸지 않는다.
- PvP를 고려하되 1차 MVP의 AI 스토리 모드 구현을 먼저 안정화한다.

## 2. 현재 기준 컨셉

### 2.1 핵심 감각

게임은 카드덱 UI나 일반 전투 UI가 아니라, 플레이어가 실제로 의식장 테이블 앞에 앉아 살아남기 위해 위험한 의식 도구를 선택하는 느낌을 목표로 한다.

- 버튼을 누르는 게임이 아니라, 의식 도구를 집는 게임
- 괴이를 HP로 죽이는 게임이 아니라, 진명을 밝혀 봉인하는 게임
- 플레이어 상태는 숫자 게이지보다 신체 붕괴와 시야 왜곡으로 체감
- 괴이 진척은 체력 게이지가 아니라 거울 파괴와 반사상 붕괴로 표현
- 정보 시스템은 기록서, 단서 조각, 오염된 거짓 단서 중심으로 표현

## 3. 확정된 시각/자원 설계

### 3.1 괴이 진척 표현

괴이에게 체력 게이지를 두지 않는다. 괴이의 약화나 진척 상태는 `진명 조각`과 `봉인 진행도`를 기준으로 표현한다.

| 상태 | 표현 |
|---|---|
| 진명 조각 0개 | 거울 온전, 괴이 형체 선명 |
| 진명 조각 1개 | 거울 표면에 얇은 금 발생 |
| 진명 조각 2개 | 프레임 일부 뒤틀림, 반사상 흔들림 |
| 진명 조각 3개 | 거울 대형 균열, 괴이 이름/형체 일부 노출 |
| 봉인 시도 | 봉인지와 붉은 실이 거울 균열 위에 연결 |
| 봉인 성공 | 거울 내부 붕괴, 괴이가 프레임 안으로 접힘 |
| 봉인 실패 | 균열 복구, 플레이어 시야와 팔에 반동 |

설계 이유:

- 기존 문서의 AI 스토리 승리 조건과 충돌하지 않는다.
- 괴이를 죽이는 전투가 아니라 정체를 밝혀 봉인하는 게임이라는 정체성이 살아난다.

### 3.2 행동 7종의 물리 표현

행동은 카드나 버튼이 아니라 의식 도구로 표현한다.

| 행동 | 최종 물리 표현 | 선택 행위 | 설계 이유 |
|---|---|---|---|
| 저주 | 검은 못과 중앙 의식판 | 못을 테이블에 계속 박는 것이 아니라, 중앙 의식판의 균열에 밀어 넣는다. 결과 후 못은 검은 재나 녹슨 흔적으로 사라진다. | 반복 행동으로 써도 물리적으로 어색하지 않다. |
| 수호 | 자기 앞에 세우는 접힌 수호지 또는 작은 종이 인형 방패 | 손목이 아니라 플레이어 앞에 펼쳐 저주를 받아낸다. | 팔의 붉은 실/괴사 효과와 헷갈리지 않는다. |
| 간파 | 금 간 렌즈 | 렌즈를 들어 괴이의 반사상, 그림자, 물결, 문틈 등을 본다. | `거울 속의 손님`에만 묶이지 않고 다른 괴이에도 재사용 가능하다. |
| 속임수 | 이중 의미의 가짜 의식 표식 | 플레이어가 쓰면 괴이의 판단을 흐리는 미끼 표식. 괴이가 쓰면 플레이어에게 거짓 단서를 심는 표식. | 플레이어가 자기 단서판에 가짜 단서를 넣는 설정 오류를 피한다. |
| 침묵 | 봉합된 입 부적과 살아남은 촛불 | 입 부적을 뒤집고 아무 응답도 하지 않는다. 대신 촛불 하나가 꺼지지 않아 다음 턴 의식력이 보존된다. | 정보 차단과 의식력 보존 의미가 연결된다. |
| 계약 | 붉은 실로 묶인 계약서 | 계약서를 펼치면 손목의 붉은 실이 조여든다. 성공하면 목표 진척, 실패하면 매듭이 늘어나 저주 흔적 증가. | 고위험 행동과 저주 흔적 증가가 자연스럽게 연결된다. |
| 봉인 | 잠겨 있다가 드러나는 긴 봉인지 | 진명 조각 3개 확보 전에는 보이지 않거나 잠겨 있다. 조건 충족 후 기록서 사이에서 드러나고, 거울에 붙여 최종 봉인을 시도한다. | 조건부 행동이라는 규칙과 UX가 맞는다. |

추가 원칙:

- `봉인`은 AI 스토리 전용 최종 행동이다.
- `봉인`은 처음부터 일반 선택지처럼 보여주지 않는다.
- 플레이어의 `속임수`와 괴이의 `속임수`는 같은 행동명이지만 효과 해석을 분리한다.
- 팔에 나타나는 붉은 실과 괴사는 `저주 흔적`과 `이성 붕괴` 표현으로 남긴다.

### 3.3 이성 표현

플레이어의 `이성`은 체력 게이지처럼 보이기보다, 플레이어의 시야와 신체가 무너지는 방식으로 표현한다.

| 이성 구간 | 표현 |
|---|---|
| 12-9 | 정상 시야, 손 떨림 거의 없음 |
| 8-5 | 화면 가장자리 흐림, 촛불 번짐, 손끝 변색 |
| 4-2 | 화면 흔들림, 손목 검은 반점, 선택 시 손 떨림 |
| 1 | 시야 암전 직전, 손이 도구를 놓칠 듯 흔들림 |
| 0 | 손이 테이블에 떨어지고 패배 |

### 3.4 의식력 표현

의식력은 실제 값 `0-5`를 유지하되, 화면에는 혼불 5개를 나열하지 않는다.

주 표현은 `하나의 푸른 혼불`이며, 밝기/크기/잔불과 작은 숫자 보조로 상태를 보여준다.

| 의식력 | 시각 표현 |
|---:|---|
| 0 | 혼불이 꺼지고 그릇에 재만 남음 |
| 1 | 거의 꺼질 듯한 작은 불씨 |
| 2 | 약하지만 안정된 푸른 불 |
| 3 | 기본 상태. 선명한 푸른 혼불 |
| 4 | 혼불이 커지고 주변에 잔불 1개 |
| 5 | 큰 혼불 + 잔불 2개, 그릇에 푸른 금이 감 |

연출 규칙:

- 매 턴 시작 시 의식력 2 회복: 꺼져가던 혼불이 다시 살아난다.
- 행동 비용 지불: 혼불 일부가 선택한 의식 도구로 빨려 들어간다.
- 의식력 부족: 해당 도구 앞에서 혼불이 꺼지고 손이 멈춘다.
- 침묵 사용: 아무 말도 하지 않는 대신 혼불이 보존되거나 조금 살아난다.

### 3.5 저주 흔적 표현

`저주 흔적`은 손목의 붉은 실 매듭, 검은 반점, 피부 균열로 표현한다.

| 저주 흔적 | 시각 표현 | 체감 |
|---:|---|---|
| 0 | 손목에 아무 흔적 없음 | 아직 안전 |
| 1 | 붉은 실 한 가닥이 손목에 감김 | 무언가 연결됨 |
| 2 | 실에 첫 매듭이 생기고 피부가 눌림 | 저주가 고정됨 |
| 3 | 손등 쪽으로 검은 반점이 번짐 | 위험이 눈에 보이기 시작 |
| 4 | 피부 균열, 붉은 실이 손목을 파고듦 | 다음 실수가 치명적 |
| 5 | 실이 손목 안으로 파고들고 손이 검게 굳음 | 계약 실패/괴이 저주 피격 시 즉시 패배 위험 |

구분 원칙:

- `이성 감소`: 몸과 시야가 무너지는 현재 생존력 붕괴
- `저주 흔적`: 저주가 몸에 묶이는 누적 위험

### 3.6 의심 표현

`의심`은 금 간 렌즈와 눈동자 반사로 표현한다.

| 의심 | 효과 | 시각 표현 |
|---:|---|---|
| 0 | 보정 없음 | 렌즈가 흐리고 조용함 |
| 1 | `간파 vs 속임수` 성공률 +10% | 렌즈 가장자리에 얇은 금 1개 |
| 2 | 성공률 +20% | 금이 2개로 늘고 반사상이 흔들림 |
| 3 | 성공률 +30% | 렌즈 안쪽에 괴이의 눈동자 반사가 잠깐 보임 |
| 판정 후 | 의심 0 초기화 | 렌즈가 흐려지고 금이 사라짐 |

확정 원칙:

- 서버/문서상 상태명은 `의심`으로 유지한다.
- UI에서는 보조 표시로 `의심 2/3` 또는 렌즈 아이콘 3칸을 사용할 수 있다.
- 주 표현은 렌즈 균열이다.
- 의심 상승 시 유리 긁힘 소리 또는 렌즈 떨림 연출을 사용한다.
- `간파 vs 속임수` 판정 후 렌즈가 흐려지며 의심이 초기화된다.
- 의심은 나쁜 디버프가 아니라, 속임수를 읽어낼 가능성이 높아지는 위험한 집중 상태로 설명한다.

### 3.7 보호막 표현과 지속 규칙

보호막은 최대 `1개`만 유지한다.

| 항목 | 값 |
|---|---|
| 최대 보유량 | 1 |
| 효과 | 다음 저주 피해 -1 |
| 발동 조건 | 저주 피해를 받을 때 |
| 발동 후 | 보호막 제거 |
| 중복 획득 | 무시 |

확정 원칙:

- 보호막은 저주 피해를 실제로 막아낸 `수호` 성공 보상으로만 생성된다.
- 공격이 없는 턴의 `수호`는 보호막을 만들지 않는다.
- 보호막은 저주 외 피해나 저주 흔적 증가에는 적용하지 않는다.

시각 표현:

- 수호 성공 시 접힌 수호지 또는 종이 인형 방패가 플레이어 앞에 세워진다.
- 보호막 보유 중에는 수호지 가장자리에 옅은 푸른/흰 빛이 돈다.
- 저주를 맞으면 수호지가 먼저 타들어가고 저주 피해가 1 줄어든다.
- 발동 후 수호지는 재가 되어 사라진다.

### 3.8 봉인 방해 단계

봉인은 `진명 조각 3개` 확보 후 사용할 수 있는 AI 스토리 전용 단일 턴 최종 행동이다.

| 상대 행동 | 봉인 방해 단계 | 판정 |
|---|---:|---|
| 저주 | +1 | 단독으로는 봉인 실패 불가 |
| 간파 | +1 | 단독으로는 봉인 실패 불가 |
| 속임수 | +2 | 봉인 실패 |
| 계약 | +2 | 봉인 실패 |
| 침묵 | +0 | 봉인 성공 |
| 수호 | +0 | 봉인 성공 |
| 봉인 | AI 스토리에서는 괴이가 사용하지 않음 |

| 방해 단계 | 결과 | 연출 |
|---:|---|---|
| 0 | 완전 성공 | 봉인지가 거울에 깨끗하게 붙고, 균열이 봉인 문양으로 이어짐 |
| 1 | 불안정 성공 | 봉인지가 찢어지지만 붉은 실이 붙잡고, 거울이 흔들린 뒤 봉인 성공 |
| 2 이상 | 실패 | 봉인지가 검게 타며 찢어지고, 거울 균열이 되감김 |

봉인 실패 반동:

- 이성 -1
- 저주 흔적 +1

## 4. 확정된 정보 시스템

### 4.1 정보 공개 방식

`진명 조각 / 불완전한 진명 조각 / 거짓 단서`는 계층형 공개로 처리한다.

| 정보 | 위치 | 진위 공개 방식 |
|---|---|---|
| 진명 조각 | 기록서 중앙 도식 | 확정 진짜로 공개 |
| 불완전한 진명 조각 | 중앙 도식 옆 임시 슬롯 | 진짜 후보로 표시 |
| 거짓 단서 | 기록서 가장자리/여백 | 처음엔 불명확, 간파 성공 또는 결과 화면에서 공개 |

확정 규칙:

- 플레이어는 항상 `진명 조각 0/3`, `1/3`, `2/3`, `3/3` 상태를 알 수 있다.
- `진명 조각`은 기록서 중앙 도식에 고정된다.
- `거짓 단서`는 봉인 조건에 포함되지 않는다.
- `거짓 단서`는 처음부터 노골적으로 가짜처럼 표시하지 않는다.
- `간파` 성공 시 거짓 단서가 제거되거나 정체가 드러날 수 있다.
- 결과 화면에서는 획득한 정보의 진위가 공개된다.
- `불완전한 진명 조각 2개`가 모이면 자동으로 `진명 조각 +1`로 정리된다.

### 4.2 거울 속의 손님: 정보 대상

각 정보 대상은 진명 조각 하나와 1:1로 연결된다.

| 정보 대상 | 진명 조각 |
|---|---|
| 거울 | 깨진 거울의 뒷면에 남은 이름 |
| 목소리 | 사라진 아이의 마지막 목소리 |
| 방 번호 | 플레이어가 잊어버린 자기 방 번호 |

### 4.3 금기와 누적 조건

금기:

> 같은 정보 대상을 연속으로 묻지 말 것.

질문 행동:

- `간파`
- `계약`

비질문 행동:

- `저주`
- `수호`
- `속임수`
- `침묵`
- `봉인`

금기 위반 조건:

- 직전 정보 요청 대상과 같은 대상을 다시 선택하면 금기 위반이다.
- 행동이 달라도 정보 대상이 같으면 위반이다.
- 중간에 `저주`, `수호`, `속임수`, `침묵` 같은 비질문 행동을 사용하면 질문 흐름은 끊긴다.

예:

- `간파 + 거울` -> `계약 + 거울`: 금기 위반
- `간파 + 거울` -> `수호` -> `계약 + 거울`: 금기 위반 아님
- `계약 + 목소리` -> `간파 + 방 번호`: 금기 위반 아님

금기 위반 효과:

- 저주 흔적 +1
- 다음 괴이 행동에서 `속임수`와 `저주` 가중치 증가
- 공개 로그: `같은 질문이 거울 속에서 두 번 울렸다.`

### 4.4 진명 조각 획득 조건

| 행동 결과 | 정보 보상 |
|---|---|
| 플레이어 계약 완전 성공 | 선택 대상의 진명 조각 +1 |
| 플레이어 계약 부분 성공 | 선택 대상의 불완전한 진명 조각 +1 |
| 플레이어 간파가 괴이 계약을 읽음 | 선택 대상의 불완전한 진명 조각 +1 |
| 플레이어 간파가 속임수를 판별 | 거짓 단서 제거. 불완전한 진명 조각 없음 |
| 플레이어 간파가 침묵을 읽음 | 다음 행동 후보 2개 확인. 불완전한 진명 조각 없음 |
| 불완전한 진명 조각 2개 | 선택 대상의 진명 조각 +1로 변환 |

확정 원칙:

- `간파`는 진명 조각을 직접 캐는 만능 행동이 아니다.
- `계약`이 진명 획득의 핵심 경로다.
- `간파`는 계약을 읽거나 속임수를 제거해 위험을 줄이는 보조 행동이다.
- `속임수`를 간파해도 불완전한 진명 조각은 주지 않는다. 거짓 단서 제거만 한다.
- 이미 획득한 대상의 진명 조각은 다시 얻을 수 없다.
- 이미 진명 조각을 얻은 대상에 정보 요청을 하면 금기 위반 여부와 별개로 추가 진척은 없다.
- 불완전한 진명 조각은 대상별로 관리한다.
- 불완전한 조각 2개가 진명 조각으로 변환되면 해당 대상의 불완전 조각은 0으로 초기화된다.

### 4.5 거짓 단서 trigger condition

거짓 단서는 AI 스토리 전용 정보 오염 자원이다. 봉인 조건에는 포함되지 않으며, 처음부터 명확히 가짜라고 표시하지 않는다.

거짓 단서 목록:

| 거짓 단서 | 성격 |
|---|---|
| 거울을 깨면 끝난다 | 거울 대상 집착을 유도하는 거짓 해결책 |
| 불을 끄면 안전하다 | 시간초과, 시야 저하, 공포 회피를 유도하는 거짓 안전책 |
| 이름을 부르면 괴이가 약해진다 | 목소리/이름/계약을 오해하게 만드는 거짓 단서 |

거짓 단서 생성 조건:

| 상황 | 처리 |
|---|---|
| 괴이 속임수 성공 | 거짓 단서 +1 |
| 플레이어가 `간파 vs 속임수` 판정 실패 | 거짓 단서 +1 |
| 시간초과 3회로 `거울 응시` 발동 | 거짓 단서 +1 |

거짓 단서 선택 우선순위:

1. `거울 응시` 발생이면 `불을 끄면 안전하다` 우선
2. 현재 정보 대상이 `거울`이면 `거울을 깨면 끝난다` 우선
3. 현재 정보 대상이 `목소리`이면 `이름을 부르면 괴이가 약해진다` 우선
4. 이성 4 이하에서 생성되면 `불을 끄면 안전하다` 우선
5. 금기 위반 직후 생성이면 현재 대상 연결 단서 우선
6. 그래도 결정되지 않으면 아직 없는 거짓 단서 중 선택
7. 이미 보유 중인 거짓 단서는 중복 생성하지 않음
8. 거짓 단서가 이미 3개면 추가 생성하지 않음

방 번호 대상 처리:

- `방 번호`에는 전용 거짓 단서를 추가하지 않는다.
- 방 번호 대상에서 거짓 단서가 생성될 경우 fallback 규칙을 따른다.
- 새 거짓 단서 문구는 현재 문서 범위를 넘기므로 지금 추가하지 않는다.

간파 성공 시 제거 규칙:

1. 현재 정보 대상과 연결된 거짓 단서가 있으면 우선 제거
2. 없으면 가장 오래된 거짓 단서 제거
3. 제거된 단서는 검게 타거나 기록서에서 떨어져 나가는 연출 사용

## 5. 확정된 상성표 추가 행

기존 문서에는 `저주`, `수호`, `간파` 행 일부가 이미 있었다. 대화에서는 누락되어 있던 `속임수`, `침묵`, `계약`, `봉인` 행을 보강했다.

### 5.1 속임수 행

| 내 행동 | 상대 행동 | 결과 | 공개 로그 방향 |
|---|---|---|---|
| 속임수 | 저주 | 속임수 사용자 이성 -1, 저주 사용자 의심 +1 | 거짓 표식 사이로 저주가 스쳤다. 완전히 숨기지는 못했지만 흔적은 남았다. |
| 속임수 | 수호 | 속임수 성공. 괴이 속임수라면 플레이어 거짓 단서 +1. 플레이어 속임수라면 괴이 다음 행동 후보 교란. 수호자 보호막 없음 | 수호는 잘못된 위협을 향했고, 거짓 표식이 의식장에 섞였다. |
| 속임수 | 간파 | `간파 vs 속임수` 확률 판정 적용. 성공 시 이번 속임수 차단 및 기존 거짓 단서 1개 제거, 실패 시 거짓 단서 +1. 판정 후 의심 0 초기화 | 렌즈가 거짓 표식을 더듬었다. 진실과 거짓 중 하나가 모습을 드러냈다. |
| 속임수 | 속임수 | 양쪽 효과 없음 | 두 거짓 표식이 서로를 가렸다. 의식장은 아무것도 증명하지 못했다. |
| 속임수 | 침묵 | 침묵자는 다음 턴 의식력 +1. 괴이 속임수라면 플레이어 거짓 단서 +1. 플레이어 속임수라면 괴이 다음 행동 후보 교란 | 침묵은 거짓을 반박하지 않았다. 조용한 의식장에 낯선 표식만 남았다. |
| 속임수 | 계약 | 계약 실패, 계약자 저주 흔적 +1 | 계약서의 이름 사이에 거짓 표식이 끼어들었다. 대가는 비틀렸다. |
| 속임수 | 봉인 | 봉인 방해 단계 +2, 봉인 실패 | 봉인의 문장에 거짓 이름이 섞였다. 봉인지는 검게 타 찢어졌다. |

추가 원칙:

- `속임수`는 직접 피해 행동이 아니다.
- `속임수`는 정보 오염, 판단 교란, 봉인 방해에 강하다.
- 플레이어와 괴이의 `속임수 성공 효과`는 다르게 해석한다.
  - 괴이 속임수 성공: 플레이어 기록서에 거짓 단서 +1
  - 플레이어 속임수 성공: 괴이 다음 행동 후보 교란
- 플레이어가 자기 기록서에 거짓 단서를 넣는 상황은 만들지 않는다.
- 괴이가 기록서를 가진 것처럼 처리하지 않는다.
- `속임수 vs 계약`에서는 속임수 사용자에게 추가 의심 보정을 주지 않는다.
- `속임수 vs 속임수`는 양쪽 효과 없음으로 단순 처리한다.
- `속임수 vs 봉인`은 방해 +2로 유지하되, 괴이 AI 정책에서 억울한 연속 봉인 차단이 생기지 않게 별도 조절한다.

### 5.2 침묵 행

| 내 행동 | 상대 행동 | 결과 | 공개 로그 방향 |
|---|---|---|---|
| 침묵 | 저주 | 침묵자 이성 -2 | 침묵은 저주를 막지 못했다. 조용한 의식장에 균열이 번졌다. |
| 침묵 | 수호 | 침묵자 다음 턴 의식력 +1, 수호자 효과 없음 | 수호는 허공을 지켰고, 침묵은 다음 의식을 준비했다. |
| 침묵 | 간파 | 단서 획득 실패, 간파자는 침묵자의 다음 행동 후보 2개 확인 | 침묵은 답을 내놓지 않았다. 대신 다음 의식의 방향이 조금 좁혀졌다. |
| 침묵 | 속임수 | 침묵자 다음 턴 의식력 +1. 괴이 속임수라면 플레이어 거짓 단서 +1. 플레이어 속임수라면 괴이 행동 후보 교란 | 침묵은 거짓을 반박하지 않았다. 조용한 의식장에 낯선 표식만 남았다. |
| 침묵 | 침묵 | 양쪽 다음 턴 의식력 +1. 의식력 최대 5 제한 적용 | 아무도 대답하지 않았다. 촛불만 낮게 살아남았다. |
| 침묵 | 계약 | 계약 성공. 플레이어 계약 성공이면 진명 조각 +1. 괴이 계약 성공이면 플레이어 저주 흔적 +1 | 침묵은 계약을 막지 못했다. 대가가 조용히 받아들여졌다. |
| 침묵 | 봉인 | 봉인 방해 단계 +0, 봉인 성공 | 침묵은 봉인의 문장을 막지 못했다. 거울의 균열이 하나로 이어졌다. |

확정 원칙:

- 침묵은 방어가 아니다. 저주를 막지 못한다.
- 침묵은 정보를 내놓지 않지만, 의식력을 보존한다.
- 침묵은 수호를 낭비시킨다.
- 침묵은 간파에 읽히지만 단서를 주지 않는다.
- 침묵은 속임수를 반박하지 못해 정보 오염에 취약하다.
- 침묵은 계약과 봉인을 막지 못한다.
- 계약은 주체별 효과를 분리한다.
  - 플레이어 계약 성공: 진명 조각 +1
  - 괴이 계약 성공: 플레이어 저주 흔적 +1

### 5.3 계약 행

| 내 행동 | 상대 행동 | 결과 | 공개 로그 방향 |
|---|---|---|---|
| 계약 | 저주 | 계약자 이성 -2, 계약 실패 | 계약이 맺어지기 전에 저주가 끼어들었다. 대가는 허공으로 흩어졌다. |
| 계약 | 수호 | 주체별 부분 성공. 플레이어 계약이면 플레이어 저주 흔적 +1, 불완전한 진명 조각 +1. 괴이 계약이면 플레이어 의식력 -1, 저주 흔적 증가는 없음 | 수호는 계약을 온전히 막지 못했다. 그러나 대가의 일부만 의식장에 남았다. |
| 계약 | 간파 | 계약 실패. 계약자 저주 흔적 +2. 간파자가 플레이어라면 불완전한 진명 조각 +1 | 계약의 빈틈이 드러났다. 맺어지지 못한 대가가 계약자에게 되돌아갔다. |
| 계약 | 속임수 | 계약 실패, 계약자 저주 흔적 +1 | 계약서의 이름 사이에 거짓 표식이 끼어들었다. 대가는 비틀렸다. |
| 계약 | 침묵 | 계약 성공. 플레이어 계약이면 진명 조각 +1. 괴이 계약이면 플레이어 저주 흔적 +1 | 침묵은 계약을 막지 못했다. 대가가 조용히 받아들여졌다. |
| 계약 | 계약 | 양쪽 계약 실패. 플레이어 저주 흔적 +1. 진명 진척 없음 | 두 계약이 서로의 대가를 물고 늘어졌다. 인간의 손목에 매듭 하나만 더 남았다. |
| 계약 | 봉인 | 봉인 방해 단계 +2, 봉인 실패 | 봉인의 대가가 뒤집혔다. 거울은 다시 괴이의 이름을 삼켰다. |

확정 원칙:

- 플레이어 계약 성공: 진명 진척
- 괴이 계약 성공: 플레이어 저주 흔적 증가
- 플레이어 계약 부분 성공: 불완전한 진명 조각 +1 + 저주 흔적 +1
- 괴이 계약 부분 성공: 플레이어 의식력 -1
- 계약 실패: 계약자에게 반동
- 계약은 고위험 행동이므로 읽히면 손해가 커야 한다.
- 공식 docs에 반영할 때 기존 `수호 vs 계약` 문구는 주체별 효과로 수정해야 한다.

### 5.4 봉인 행

봉인은 AI 스토리에서 플레이어만 사용한다.

| 내 행동 | 상대 행동 | 결과 | 공개 로그 방향 |
|---|---|---|---|
| 봉인 | 저주 | 봉인 방해 단계 +1. 봉인 성공. 봉인자 이성 -2 적용. 이후 동시 승패 우선순위 검사 | 봉인의 문장이 흔들렸다. 그러나 저주 하나로는 이름을 다시 숨기지 못했다. |
| 봉인 | 수호 | 봉인 방해 단계 +0. 봉인 성공 | 수호의 막은 봉인의 문장을 막지 못했다. 거울의 균열이 하나로 이어졌다. |
| 봉인 | 간파 | 봉인 방해 단계 +1. 봉인 성공 | 괴이가 봉인의 획을 읽어냈다. 그러나 이미 드러난 이름은 다시 감춰지지 않았다. |
| 봉인 | 속임수 | 봉인 방해 단계 +2. 봉인 실패. 이성 -1, 저주 흔적 +1 | 봉인의 문장에 거짓 이름이 섞였다. 봉인지는 검게 타 찢어졌다. |
| 봉인 | 침묵 | 봉인 방해 단계 +0. 봉인 성공 | 아무 대답도 돌아오지 않았다. 침묵 속에서 봉인지가 거울에 붙었다. |
| 봉인 | 계약 | 봉인 방해 단계 +2. 봉인 실패. 이성 -1, 저주 흔적 +1 | 봉인의 대가가 뒤집혔다. 거울은 다시 괴이의 이름을 삼켰다. |
| 봉인 | 봉인 | AI 스토리에서는 발생하지 않음 | 해당 없음 |

확정 원칙:

- 봉인은 AI 스토리에서 플레이어만 사용한다.
- 진명 조각 3개가 없으면 선택 불가.
- 비용은 2.
- 괴이는 봉인을 사용하지 않는다.
- 방해 단계 0-1은 성공.
- 방해 단계 2 이상은 실패.
- `저주`, `간파`는 봉인을 흔들지만 단독 실패는 만들 수 없다.
- `속임수`, `계약`은 봉인을 실패시킨다.
- 봉인 실패 반동은 이성 -1, 저주 흔적 +1.
- `봉인 vs 저주`처럼 승리/패배가 동시에 걸릴 수 있는 경우는 동시 승패 우선순위에서 처리한다.

## 6. 확정된 승패/시간 처리

### 6.1 동시 승패 우선순위

턴 결과는 아래 순서로 검사한다.

1. 턴 결과 계산
2. 봉인 성공 여부 검사
3. 봉인 성공이면 즉시 플레이어 승리
4. 봉인 실패 또는 봉인 없음이면 이성 0 검사
5. 저주 흔적 패배 조건 검사
6. 제한 턴 검사
7. 다음 턴 진행

상황별 판정:

| 상황 | 판정 |
|---|---|
| 봉인 성공 + 이성 0 | 플레이어 승리 |
| 봉인 성공 + 저주 흔적 패배 조건 | 플레이어 승리 |
| 봉인 실패 + 이성 0 | 플레이어 패배 |
| 봉인 실패 + 저주 흔적 5 도달 | 즉시 패배 아님 |
| 이성 0 + 진명 조각 획득 | 플레이어 패배 |
| 12턴 종료 + 진명 조각 3개 확보 | 플레이어 패배 |
| 12턴 안에 봉인 선언 성공 | 플레이어 승리 |
| 저주 흔적 5 상태에서 계약 실패 또는 괴이 저주 피격 | 플레이어 패배 |

확정 이유:

- 봉인은 최종 승리 시도이므로 성공한 순간 이성 0보다 우선한다.
- `저주`와 `간파`는 봉인을 흔들 수 있지만 단독 실패는 만들 수 없다는 기존 결정과 맞다.
- 저주 흔적은 5가 되었다고 즉시 패배가 아니다. 문서상 패배 조건은 `저주 흔적 5 상태에서 계약 실패 또는 괴이 저주 피격`이다.
- 진명 조각 3개 확보는 승리가 아니다. 반드시 다음 턴에 `봉인`을 선언해야 한다.
- 12턴 제한 안에 봉인까지 성공해야 한다.

### 6.2 시간초과 / 브라우저 종료 처리

| 상황 | 처리 |
|---|---|
| 제한 시간 | 기본 25초 |
| 시간초과 1회 | 해당 턴 행동을 자동 `침묵`으로 제출 |
| 시간초과 2회 | 자동 `침묵` + 저주 흔적 +1 |
| 시간초과 3회 | 자동 `침묵` + 강한 패턴 `거울 응시` 발동 |
| 시간초과 4회 이상 | 자동 `침묵` + 이성 -1 |

강한 패턴: `거울 응시`

- 이성 -1
- 저주 흔적 +1
- 거짓 단서 +1
- 다음 턴 제한 시간 -5초

거울 응시 연출:

- 플레이어가 선택하지 못한 사이 거울 속 괴이가 손을 뻗는다.
- 화면이 강제로 거울 쪽으로 당겨진다.
- 기록서 가장자리에 젖은 가짜 단서가 붙는다.
- 다음 턴 타이머가 짧아진다.

브라우저 종료 / 네트워크 끊김:

- 즉시 패배 처리하지 않는다.
- 제한 시간 안에 복귀하면 기존 턴 계속 진행.
- 제한 시간이 지나면 해당 턴은 시간초과 처리.
- 진행 중 AI 매치는 서버에 저장하고 이어하기 가능.
- MVP에서는 사용자당 진행 중 AI 매치 1개만 허용.
- 새 AI 매치를 시작하려면 기존 매치를 이어가거나 포기해야 한다.

## 7. 거울 속의 손님: 괴이 행동 정책

괴이는 LLM이 자유롭게 행동하지 않는다. 서버가 정해진 가중치와 보정 규칙을 바탕으로 행동을 선택한다.

선택은 seed 기반 weighted random으로 처리하고, seed, 최종 가중치, 선택 결과를 저장한다.

### 7.1 괴이 행동 후보

AI 스토리에서 괴이는 `봉인`을 사용하지 않는다.

| 행동 | 초기 가중치 |
|---|---:|
| 저주 | 20 |
| 수호 | 10 |
| 간파 | 16 |
| 속임수 | 22 |
| 침묵 | 18 |
| 계약 | 14 |

합계 100.

### 7.2 반영 시점

| 구간 | 처리 |
|---|---|
| 1-3턴 | 초기 가중치만 사용 |
| 3턴부터 | 상태 보정 적용 가능 |
| 4턴부터 | 최근 3턴 행동 기반 보정 적용 |
| 매 턴 종료 후 | 다음 턴 가중치 재계산 |

### 7.3 최근 3턴 행동 보정

| 조건 | 조정 |
|---|---|
| 최근 3턴 중 `간파` 2회 이상 | 속임수 +8, 침묵 -3 |
| 최근 3턴 중 `계약` 2회 이상 | 간파 +8, 저주 +4, 계약 -3 |
| 최근 3턴 중 `수호` 2회 이상 | 침묵 +8, 계약 +4, 저주 -3 |
| 최근 3턴 중 `저주` 2회 이상 | 수호 +8, 저주 -3 |
| 최근 3턴 중 `속임수` 2회 이상 | 간파 +8, 속임수 -3 |
| 시간초과 2회 이상 | 속임수 +5, 저주 +4 |

### 7.4 상태 보정

| 조건 | 조정 |
|---|---|
| 플레이어 이성 4 이하 | 저주 +6, 속임수 +4 |
| 플레이어 저주 흔적 4 이상 | 저주 +5, 계약 +4, 침묵 -3 |
| 플레이어 진명 조각 3개 보유, 첫 봉인 가능 턴 | 속임수 +3, 계약 +2, 간파 +2 |
| 플레이어 진명 조각 3개 보유, 이후 턴 | 속임수 +6, 계약 +4, 간파 +4 |

### 7.5 안전장치

- 개별 행동 최종 가중치 최대 35
- 개별 행동 최종 가중치 최소 5
- `속임수 + 계약` 합산 최종 가중치 최대 45
- 같은 행동 3턴 연속 선택 금지
- 시간초과 3회 `거울 응시`는 강한 패턴이므로 일반 행동 선택 제한과 별도 처리

### 7.6 봉인 억까 방지

- 진명 조각 3개를 모은 직후 첫 봉인 가능 턴에는 봉인 방해 보정을 절반 수준으로만 적용한다.
- 이후 턴에는 일반 봉인 가능 상태 보정을 적용한다.
- `속임수 + 계약` 합산 상한 45로 연속 봉인 차단 가능성을 제한한다.

### 7.7 저장할 값

- random_seed
- base_weights
- applied_modifiers
- final_weights
- selected_action
- selection_reason 또는 triggered_rule_summary

## 8. 아직 정하지 않은 주요 작업

### 8.1 서사 문장

아직 정해야 할 것:

- `거울 속의 손님` 브리핑 최종 문장
- 승리 후 기록 문장
- 패배 후 기록 문장
- 각 턴 공개 로그 문장 최종 검수
- 결과 화면용 정적 요약 문장

### 8.2 7x7 상성표 전체 검수

현재 대화에서 빠진 행을 보강했지만, 공식 표로 통합 검수해야 한다.

해야 할 것:

- 기존 문서의 `저주`, `수호`, `간파` 행과 새로 확정한 `속임수`, `침묵`, `계약`, `봉인` 행을 하나의 표로 병합
- 대칭 조합 중 결과가 충돌하는지 검토
- 공통 결과와 AI 스토리 결과 분리
- PvP 확장 메모 추가
- 각 조합의 공개 로그 문장 최종 정리

### 8.3 플레이어 스타일 지표 계산

아직 정해야 할 것:

- 매 턴 계산할지, 매치 종료 후 계산할지
- 전체 턴 수가 0일 때 기본값
- 위기 턴이 없을 때 `위기 방어율`, `위기 계약율` 기본값
- 결과 화면에서 숫자로 보여줄지, 라벨로 보여줄지
- 괴이 행동 정책에 반영하는 최소 표본 수

### 8.4 프론트엔드 화면 상세

아직 정해야 할 것:

- 모바일 대응 범위
- 행동 선택 시간 표시 방식
- 턴 로그 표시 위치
- 진짜 단서/거짓 단서 구분 표시 방식
- 결과 화면에서 스타일 분석을 어떻게 표현할지

## 9. 병렬로 진행 가능한 작업

### 9.1 병렬 진행 가능

아래 작업들은 서로 강하게 의존하지 않으므로 병렬로 진행 가능하다.

| 트랙 | 작업 | 병렬 가능한 이유 |
|---|---|---|
| 서사 | 브리핑/승리/패배 문장 초안 작성 | 룰 세부와 독립적으로 톤과 상황 문장을 만들 수 있다. |
| UX | 다이에제틱 UI 화면 구조 정리 | 이미 행동/자원 표현 방향이 정해져 있어 화면 설계를 병렬로 구체화할 수 있다. |
| 기술 | 인증/API prefix/error 체계 설계 | 게임 룰과 직접 의존하지 않는 백엔드 기반 결정이다. |
| 데이터 | 사용자/매치/턴/행동 제출 기본 모델 초안 | 상성표 세부와 무관하게 큰 저장 구조를 잡을 수 있다. |
| 스타일 지표 | 계산 시점/기본값/결과 표시 방식 설계 | 괴이 정책과 연결되지만 기본 계산 정책은 독립적으로 정할 수 있다. |
| 문서 | 현재 메모를 공식 문서 후보 구조로 분배 | 구현 없이 문서 구조만 잡는 작업은 병렬 가능하다. |
| PvP | 2차 PvP 개념 초안 | 공통 룰을 침범하지 않는 수준에서 후순위 설계로 병렬 진행 가능하다. |

### 9.2 병렬 진행하면 안 되는 작업

아래 작업들은 선행 결정이 없으면 충돌 가능성이 높다.

| 작업 | 먼저 필요한 결정 | 이유 |
|---|---|---|
| 공식 7x7 상성표 최종 고정 | 기존 문서 행과 대화 확정 행 병합 검수 | 대칭 조합, 주체별 효과, AI/PvP 분리 충돌을 먼저 잡아야 한다. |

| `turn_results.result_json` schema 확정 | 상성표, 확률, 거짓 단서, 봉인 결과 확정 | 결과 저장 구조가 룰 출력에 직접 의존한다. |
