# 거울 속의 손님 괴이 행동 정책

이 문서는 `거울 속의 손님`의 1차 MVP 괴이 행동 선택 기준에 대한 승인된 계약이다.

## 결정

`거울 속의 손님`은 결정적 가중치 기반 정책을 사용한다.

MVP에서는 LLM, RAG, embedding, 자유 텍스트 해석으로 괴이 행동을 선택하지 않는다.

## 기본 행동 가중치

| 괴이 행동 | 기본 가중치 |
|---|---:|
| `속임수` | 25 |
| `침묵` | 25 |
| `간파` | 15 |
| `계약` | 15 |
| `저주` | 10 |
| `수호` | 10 |
| `봉인` | 0 |

`봉인`은 괴이의 기본 선택 행동으로 사용하지 않는다.

## 스타일 반영 시작

플레이어 행동 스타일 보정은 3턴이 완료된 뒤 4턴째부터 적용한다.

1-3턴에는 기본 행동 가중치만 사용한다.

## 스타일 보정 규칙

| 플레이어 조건 | 괴이 행동 보정 |
|---|---|
| 최근 3턴 중 `간파` 2회 이상 | `속임수 +20`, `저주 +5` |
| 최근 3턴 중 `수호` 또는 `침묵` 합계 2회 이상 | `침묵 +15`, `계약 +15` |
| 최근 4턴 중 `계약` 2회 이상 | `간파 +25`, `저주 +5` |

여러 조건이 동시에 만족되면 보정을 모두 합산한다.

## 시간초과 3회 이상 강한 패턴

AI 스토리에서 플레이어의 누적 시간초과가 3회 이상이면 `거울 속의 손님`의 다음 괴이 행동은 `침묵`을 우선한다.

직전 괴이 행동이 이미 `침묵`이면 다음 괴이 행동은 `속임수`를 우선한다.

이 강한 패턴은 별도 특수 피해를 만들지 않는다. 수치 변화는 기존 상성 결과만 적용한다.

## 반복 방지

같은 괴이 행동을 3턴 연속 선택하지 않는다.

선택된 행동이 직전 2턴의 괴이 행동과 같으면 해당 행동을 이번 턴 후보에서 제외하고 다시 선택한다.

## Tie-break

동일 가중치가 발생하면 아래 순서로 선택한다.

1. `침묵`
2. `속임수`
3. `계약`
4. `간파`
5. `저주`
6. `수호`

`봉인`은 tie-break 대상에 포함하지 않는다.

## 후보 제한과의 관계

다른 규칙으로 다음 괴이 행동 후보가 제한된 경우, 서버는 제한된 후보 안에서만 이 정책을 적용한다.

예를 들어 `간파` vs `침묵` 결과로 다음 괴이 행동 후보 2개가 공개된 경우, 다음 턴 괴이 행동은 공개된 후보 2개 안에서 선택한다.

후보 2개 생성 방식은 [[09_Approved_Contracts/18_게임_규칙_상성표_상태_승패_계약]]과 [[02_Game_Rules/04_상성_규칙]]을 따른다.

## 서버 추적 필요 상태

- 최근 플레이어 행동 목록
- 최근 괴이 행동 목록
- 완료된 턴 수
- 누적 시간초과 수
- 직전 괴이 행동
- 후보 제한이 있는 경우의 제한 후보 목록
- 선택 전 기본 가중치
- 선택 전 보정 가중치
- 최종 선택 행동

## 프론트 표시 기준

프론트는 괴이 행동을 예측해서 확정 표시하지 않는다.

괴이 행동, 공개 로그, 수치 변화는 서버 응답 이후 표시한다.
