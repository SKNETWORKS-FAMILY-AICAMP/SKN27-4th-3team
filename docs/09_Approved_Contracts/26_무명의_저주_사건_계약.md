# 무명(無名)의 저주 사건 계약

이 문서는 `nameless_curse` 사건의 백엔드 seed와 LLM guardrail 기준이다.

## 핵심 결정

| 항목 | 값 |
|---|---|
| `case_id` | `nameless_curse` |
| 사건명 | `무명(無名)의 저주` |
| `apparition_id` | `2` |
| 괴이 표시명 | `피티` |
| `stage_id` | MVP 공통값 `1` |
| 표현 수위 | B안. 중간 수위의 심리 공포 |

`이안`은 고정 주인공명이 아니다. 백엔드 정적 문구, LLM prompt, fallback 문구는 `이안`을 플레이어 이름으로 쓰지 않는다.

`피티`는 `nameless_curse`에서 `거울 속의 손님`의 정체이자 진명으로 사용한다.

## 사건 브리핑

```text
사건 파일 02. 무명(無名)의 저주.

안개가 걷히지 않는 저택에는 이름을 빼앗긴 목소리가 남아 있다.
진실의 거울은 얼굴이 아니라, 숨겨진 이름과 상처를 되비춘다.

피티를 처치 대상으로 단정하지 마라.
그 이름을 되찾게 해야 저주의 사슬을 끊을 수 있다.
```

| `family_journal` | `가죽 장정 일기장` | 가문의 범죄와 지워진 이름의 기록 |

## 결과 문구 방향

- `seal_success`: 피티의 이름을 되찾게 해 봉인과 해방 사이의 결말로 기록한다.
- `sanity_zero`: 플레이어의 이름과 피티의 이름을 구분하지 못하는 자기 인식 붕괴로 기록한다.
- `curse_marks_loss`: 저주 흔적이 몸이 아니라 이름의 가장자리에 붙는 방향으로 기록한다.
- `turn_limit`: 자정이 지나 진실의 거울이 닫히고 이름을 부르지 못한 실패로 기록한다.

## LLM guardrail

`피티`는 `nameless_curse` payload에 `apparition_alias` 또는 정적 결과 문구로 들어온 경우 공식 이름으로 허용한다.

`피티`가 입력 payload에 없으면 여전히 데모 참조 누출로 막는다.

`이안`, `엘리자베스`, `무명의 저주` 같은 과거 draft/초안 고유명사는 입력 payload에 없는 경우 생성 결과에 끌어오지 않는다.

## 금지선

- LLM은 피티의 진명 공개, 단서 획득, 봉인 성공 여부를 새로 판단하지 않는다.
- RAG 검색 결과는 이 사건의 공식 단서, 진명 조각, 거짓 단서를 새로 만들 수 없다.
- PDF의 직접적인 폭력/신체 훼손 중심 표현은 1차 MVP 표시 문구로 사용하지 않는다.
