# 첫 괴이 문장 LLM 사용 기준

이 문서는 `거울 속의 손님` 문장과 LLM 사용 범위에 대한 승인된 기준이다.

## 결정

사람이 기준 문장을 작성하고 승인한다. LLM은 승인된 기준 문장을 바탕으로 판정 이후 변형/요약만 만든다.

## 작성과 승인 경계

오너는 첫 스토리의 큰 틀, 괴이 컨셉, 금기, 진명 조각, 거짓 단서 기준, 공식 기준 문장의 최종 승인 책임을 가진다.

프론트팀은 승인된 큰 틀 안에서 브리핑, 결투 진행, 결과 화면의 세부 흐름과 표현 문장 후보를 작성할 수 있다.

프론트팀이 작성한 문장 후보는 오너가 승인하기 전까지 공식 기준 문장으로 취급하지 않는다.

LLM/RAG 담당자는 별도로 있을 수 있다. LLM/RAG 담당자는 승인된 기준 문장과 문서 근거를 바탕으로 판정 이후 보조 문장, 요약, 변형 후보만 다룬다.

## 사람이 작성하고 승인하는 문장

아래 문장은 공식 기준 문장으로 다룬다.

- 사건 브리핑
- 승리 기록
- 패배 기록
- 주요 공개 로그 문장
- 진명 조각 설명
- 거짓 단서 문장

## LLM 사용 가능 후보

LLM은 아래처럼 판정 이후 보조 문장에 먼저 사용한다.

- 결과 화면용 서사 요약
- 플레이 스타일 요약 문장
- 운영자용 매치 로그 요약
- 승인된 기준 문장의 짧은 변형 후보

## LLM 금지선

LLM 생성 문장은 아래 역할을 하지 않는다.

- 전투/턴 판정
- 승패 결정
- 이성, 의식력, 저주 흔적 계산
- 진명 조각 획득 여부 결정
- 거짓 단서 진위 결정
- 공식 설정 추가
- 룰 변경

## 프론트 표시 기준

- 공식 기준 문장과 LLM 생성 문장을 UI에서 구분할 수 있어야 한다.
- LLM 생성 문장을 서버 판정 결과처럼 표시하지 않는다.
- 결과 화면에서 LLM 요약이 실패해도 정적 결과 문장으로 화면을 완성할 수 있어야 한다.
