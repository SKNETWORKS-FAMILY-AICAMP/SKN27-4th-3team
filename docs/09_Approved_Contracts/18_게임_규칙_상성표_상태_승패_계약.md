# 게임 규칙 상성표 상태 승패 계약

이 문서는 1차 MVP 게임 규칙 중 남아 있던 7x7 상성표, `간파` vs `침묵` 후보 2개 생성 방식, 상태 지속 규칙, 동시 승패 우선순위에 대한 승인 기준이다.

## 결정

A안인 결정적 완성표와 최소 상태 추가 버전을 사용한다.

## 적용 범위

- 전체 7x7 행동 상성표
- `간파` vs `침묵`으로 공개되는 다음 행동 후보 2개 생성 방식
- `공포`, `금기 위반`, `보호막`의 1차 MVP 처리
- 봉인 방해 단계
- 동시 승패 우선순위

## 전체 상성표 기준

전체 7x7 행동 상성표는 [[02_Game_Rules/04_상성_규칙]]을 따른다.

이미 확정된 `저주`, `수호`, `간파` 행은 유지한다.

새로 확정된 `속임수`, `침묵`, `계약`, `봉인` 행도 [[02_Game_Rules/04_상성_규칙]]의 공개 로그와 함께 구현한다.

표에 없는 조합을 기본 효과, 무효, 즉흥 판정으로 넘기지 않는다.

## 봉인 방해 기준

| 상대 행동 | 봉인 방해 단계 |
|---|---:|
| `속임수` | +2 |
| `계약` | +2 |
| `저주` | +1 |
| `간파` | +1 |
| `침묵` | +1 |
| `수호` | +0 |

봉인 방해 단계가 0-1이면 봉인은 성공한다.

봉인 방해 단계가 2 이상이면 봉인은 실패한다.

1차 MVP에서 괴이는 `봉인`을 선택하지 않는다.

## 다음 행동 후보 2개 생성

`간파` vs `침묵` 결과로 다음 행동 후보 2개가 공개되면 아래 순서로 생성한다.

1. 다음 턴에 선택 가능한 괴이 행동 목록을 만든다.
2. `봉인`은 제외한다.
3. `거울 속의 손님` 괴이 행동 정책의 기본 가중치, 스타일 보정, 시간초과 보정, 3연속 방지 규칙을 적용한다.
4. 가중치 상위 2개를 공개한다.
5. 동률이면 `침묵 > 속임수 > 계약 > 간파 > 저주 > 수호` 순서로 고른다.
6. 다음 턴 AI는 공개된 2개 안에서만 행동을 선택한다.

## 상태 규칙

| 상태 | 1차 MVP 처리 |
|---|---|
| 공포 | 생성하지 않고 적용하지 않는다. |
| 금기 위반 | 지속 상태가 아니라 즉시 이벤트로 저장한다. |
| 보호막 | 최대 1. 다음 저주 피해 2를 막고 소모된다. 다음 턴 종료까지 미사용이면 사라진다. |

## 동시 승패 우선순위

같은 턴에 승리와 패배 조건이 동시에 발생하면 아래 순서를 따른다.

1. 봉인 성공이 있으면 승리 우선.
2. 봉인 성공이 없고 이성 0 또는 저주 흔적 패배 조건이 발생하면 패배.
3. 12턴째 종료 시 봉인 성공이 없으면 패배.

## 구현 금지선

- LLM, RAG, embedding, 자유 텍스트 해석으로 상성 결과를 바꾸지 않는다.
- 공개 로그는 문서의 확정 문장을 사용한다.
- 봉인 방해 단계는 상성표 외부에서 임의 가산하지 않는다.
- `공포`는 1차 MVP에서 생성하지 않는다.
