# 프론트팀 전달 패키지

이 문서는 프론트팀에 전달할 승인본 묶음이다.

새로운 요구사항을 추가하지 않는다. 프론트팀이 먼저 읽을 순서, 전달 범위, 산출물 기대치를 정리한다.

## 전달 목적

프론트팀은 승인된 세계관, 역할 경계, 서버 권위, 금지선을 지키면서 화면 흐름과 표현을 설계한다.

오너는 세계관 큰 틀, 첫 스토리 핵심 구조, 공식 문장 승인, API/인증/폴더 구조 같은 기술 계약을 별도로 확정한다.

LLM/RAG는 별도 담당자가 맡을 수 있으며, 프론트팀은 LLM/RAG 결과를 서버 판정이나 공식 설정처럼 표시하지 않는다.

## 전달된 확정 기준

| 구분 | 확정 기준 |
|---|---|
| 1차 MVP 괴이 | `거울 속의 손님` 1종 |
| 게임 감각 | 카드 배틀보다 `생존 의식 테이블` |
| 프론트 역할 | 승인된 기준 안에서 화면 흐름, 표현, 연출, 문장 배치 설계 |
| 오너 역할 | 세계관 큰 틀, 첫 스토리 핵심 구조, 공식 문장, 기술 계약 승인 |
| 서버 권위 | 수치, 행동 가능 여부, 턴 결과, 단서, 봉인, 승패 |
| LLM 역할 | 판정 이후 요약, 스타일 문장, 로그 요약, 짧은 변형 후보 |
| RAG 역할 | `retrieval` 검색 구조와 로그 준비. MVP 핵심 판정에는 의존하지 않음 |
| 프론트 기술 계약 | [[09_Approved_Contracts/15_프론트_기술_계약_오너_확정안]]을 따른다 |
| 금기 판정 | 자유 텍스트가 아니라 `info_target_key` 반복 기반 |
| 괴이 행동 정책 | [[09_Approved_Contracts/16_거울_속의_손님_괴이_행동_정책]]을 따른다 |
| 시간초과 판정 | 브라우저 종료/네트워크 끊김이 아니라 서버 `deadline_at` 기준. [[09_Approved_Contracts/21_AI_스토리_시간초과_판정_계약]]을 따른다 |

## 프론트팀이 제안할 산출물

프론트팀은 아래 산출물을 제안한다.

- MVP 화면 흐름도
- route 구성 후보
- 화면별 주요 상태와 표시 정보 목록
- 브리핑 화면 UX 제안
- 의식 결투 화면 UX 제안
- 결과 화면 UX 제안
- 행동 선택 UI와 정보 대상 선택 UI 제안
- 공개 로그, 진명 조각, 거짓 단서 표시 방식
- 오류 상태 UX 제안
- 모바일/데스크톱 대응 기준
- API 의존 항목 목록

프론트팀 산출물은 오너 승인 전까지 공식 구현 기준이 아니다.

## 프론트팀이 임의 확정하지 않는 항목

아래 항목은 오너 또는 담당 영역의 승인 전까지 확정하지 않는다.

- 거짓 단서 trigger condition 변경
- 전체 7x7 행동 상성표 결과와 공개 로그
- API endpoint, request/response schema, error code
- 인증, CSRF, cookie, token 정책
- 폴더 구조, 앱 경계, DB 모델
- LLM provider와 generation 정책
- RAG provider 변경, embedding/chunking/검색 threshold 변경

## 전달 시 주의 문구

프론트팀에 이 패키지를 전달할 때 아래 문구를 함께 전달한다.

> 이 패키지는 프론트 설계 착수를 위한 승인 기준 묶음이다. 프론트팀은 화면 흐름과 표현을 제안할 수 있지만, 공식 세계관/룰/API/서버 판정은 오너 승인 전까지 확정하지 않는다. 미확정 항목은 구현하지 말고 의존 항목으로 표시한다.
