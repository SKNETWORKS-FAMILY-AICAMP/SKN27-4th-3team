# 자원과 상태

## 공통 자원

| 자원 | 기본값 | 범위 | 설명 |
|---|---:|---:|---|
| 이성 | 12 | 0-12 | 0이 되면 패배한다. |
| 의식력 | 3 | 0-5 | 행동 비용으로 사용한다. 매 턴 시작 시 2 회복한다. |
| 저주 흔적 | 0 | 0-5 | 강한 행동 실패, 계약 실패, 괴이 공격으로 증가한다. |
| 비밀 노출도 | - | - | 과거 PvP 검토안의 자원. 현재 구현 기준이 아니다. |
| 진명 조각 | 0 | 0-3 | AI 스토리에서 3개를 모아야 봉인을 시도할 수 있다. |
| 불완전한 진명 조각 | 0 | 0-1 | 2개가 되면 진명 조각 +1로 변환하고 0으로 초기화한다. |

## 보조 상태

| 상태 | 설명 | MVP 확정 상태 |
|---|---|---|
| 공포 | 다음 턴 선택 시간이 줄거나 특정 행동 비용이 오를 수 있는 확장 상태다. | 1차 MVP 미사용 |
| 의심 | 의심 1당 다음 `간파` vs `속임수` 판정 성공률이 +10% 오른다. 최대 3까지 누적되며 간파 판정 후 0으로 초기화한다. | 사용 |
| 금기 위반 | 괴이별 금기 trigger가 발생했음을 남기는 이벤트다. | 즉시 이벤트 |
| 거짓 단서 | 단서처럼 보이지만 봉인에 도움이 되지 않는 정보다. 최대 3개까지 보유한다. | 사용 |
| 보호막 | 다음 저주 피해 2를 막고 소모된다. | 사용 |
| 봉인 방해 단계 | 봉인 턴에만 계산하는 임시 값이다. 2 이상이면 봉인이 실패하고, 0-1이면 봉인이 성공한다. | 사용 |

## 불완전한 진명 조각 규칙

- 불완전한 진명 조각은 AI 스토리 전용 자원이다.
- 불완전한 진명 조각이 2개가 되면 진명 조각 +1로 변환한다.
- 변환 직후 불완전한 진명 조각은 0으로 초기화한다.
- 진명 조각이 이미 3개인 경우 불완전한 진명 조각 변환은 발생하지 않는다.

## 의심 규칙

- 의심은 최대 3까지 누적된다.
- 의심 1당 다음 `간파` vs `속임수` 판정 성공률이 +10% 오른다.
- `간파` vs `속임수`의 기본 성공률은 50%다.
- 의심 보정 후 최종 성공률 상한은 80%다.
- `간파` vs `속임수` 판정 후 의심은 0으로 초기화한다.

## 거짓 단서 규칙

- 거짓 단서는 최대 3개까지 보유한다.
- `간파` vs `속임수` 실패 시 거짓 단서 +1을 적용한다.
- 거짓 단서가 이미 3개이면 추가하지 않는다.
- `간파` vs `속임수` 성공 시 이번 속임수를 차단한다.
- 성공 시 기존 거짓 단서가 있으면 1개 제거한다.

## 공포 규칙

- 1차 MVP에서 공포는 생성하지 않는다.
- 1차 MVP에서 공포는 선택 시간, 행동 비용, 상성 결과에 영향을 주지 않는다.
- 공포는 후속 확장 상태로만 보존한다.

## 금기 위반 규칙

- 금기 위반은 지속 상태가 아니라 즉시 이벤트로 저장한다.
- 금기 위반 이벤트는 괴이별 거짓 단서 trigger condition에 사용될 수 있다.
- 금기 위반 이벤트는 다음 턴으로 지속되지 않는다.
- 금기 위반 이벤트는 행동 비용, 선택 가능 행동, 봉인 방해 단계에 직접 영향을 주지 않는다.

## 보호막 규칙

- 보호막은 최대 1이다.
- 보호막은 다음 저주 피해 2를 막고 소모된다.
- 보호막이 이미 1이면 추가 보호막은 누적되지 않고 1로 유지된다.
- 보호막은 다음 턴 종료까지 미사용이면 사라진다.
- 공격이 없는 턴의 `수호`는 보호막을 만들지 않는다.
