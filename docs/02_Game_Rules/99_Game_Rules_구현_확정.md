# Game Rules 구현 확정

이 문서는 게임 규칙 구현 착수 전 승인받는 최종 기준 문서다.

## 확정 전 조건

- 현재 남은 게임 규칙 결정 없음

## 확정된 규칙 결정

| 결정 | 확정값 |
|---|---|
| 1차 MVP AI 스토리 제한 턴 수 | 12턴 |
| 2차 업데이트 제한 턴 수 후보 | 15턴 |
| 행동 상성표 범위 | 전체 7x7 조합을 문서로 확정한다. |
| 행동 상성표 작성 형식 | 각 조합마다 수치/상태 결과와 화면 공개 로그 문장을 함께 확정한다. |
| `저주` 행 | [[02_Game_Rules/04_상성_규칙]]의 확정된 저주 행을 따른다. |
| `수호` 행 | [[02_Game_Rules/04_상성_규칙]]의 확정된 수호 행을 따른다. |
| `간파` 행 | [[02_Game_Rules/04_상성_규칙]]의 확정된 간파 행을 따른다. |
| `속임수` 행 | [[02_Game_Rules/04_상성_규칙]]의 확정된 속임수 행을 따른다. |
| `침묵` 행 | [[02_Game_Rules/04_상성_규칙]]의 확정된 침묵 행을 따른다. |
| `계약` 행 | [[02_Game_Rules/04_상성_규칙]]의 확정된 계약 행을 따른다. |
| `봉인` 행 | [[02_Game_Rules/04_상성_규칙]]의 확정된 봉인 행을 따른다. |
| `간파` vs `침묵` 다음 행동 후보 2개 | [[02_Game_Rules/04_상성_규칙]]의 후보 2개 생성 방식을 따른다. |
| 저주 충돌 주사위 | [[02_Game_Rules/07_확률_판정]]의 저주 충돌 주사위 규칙을 따른다. |
| 거짓 단서 판별 | [[02_Game_Rules/07_확률_판정]]의 거짓 단서 판별 규칙을 따른다. |
| 봉인 방해 기준 | 봉인은 단일 턴 행동이다. 방해 단계 2 이상이면 실패, 0-1이면 성공한다. |
| 불완전한 진명 조각 | 2개가 되면 진명 조각 +1로 변환하고 0으로 초기화한다. |
| 공포 | 1차 MVP에서 생성하거나 적용하지 않는다. |
| 금기 위반 | 지속 상태가 아니라 즉시 이벤트로 저장한다. |
| 보호막 | 최대 1. 다음 저주 피해 2를 막고 소모된다. 다음 턴 종료까지 미사용이면 사라진다. |
| 동시 승패 우선순위 | 봉인 성공이 있으면 승리 우선. 봉인 성공이 없으면 패배 조건을 적용한다. |
| `거울 속의 손님` 시간초과 3회 이상 강한 패턴 | [[02_Game_Rules/06_시간초과_규칙]]과 [[09_Approved_Contracts/16_거울_속의_손님_괴이_행동_정책]]을 따른다. |
| 브라우저 종료/네트워크 끊김 | 즉시 시간초과로 보지 않는다. 서버 `deadline_at`까지 유효 제출이 없을 때 시간초과로 처리한다. |
| 시간초과 판정 기준 | [[09_Approved_Contracts/21_AI_스토리_시간초과_판정_계약]]을 따른다. |
| `거울 속의 손님` 괴이별 특수 패턴 확률 | 1차 MVP에서는 사용하지 않는다. |

상세 기준은 [[09_Approved_Contracts/18_게임_규칙_상성표_상태_승패_계약]]을 따른다.
