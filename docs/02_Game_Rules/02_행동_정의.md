# 행동 정의

| 행동 | 비용 | 기본 효과 | MVP 사용 |
|---|---:|---|---|
| 저주 | 2 | 상대 이성 2 감소 | 사용 |
| 수호 | 1 | 저주 피해 2 감소, 보호막 1 획득 | 사용 |
| 간파 | 1 | 단서 판별 또는 상대 행동 성향 일부 확인 | 사용 |
| 속임수 | 1 | 거짓 단서 생성, 간파 방해 | 사용 |
| 침묵 | 0 | 정보 공개 차단, 다음 턴 의식력 +1 | 사용 |
| 계약 | 3 | 성공 시 진명 조각 또는 비밀 노출도 +1 | AI 스토리 진명 조각 용도로 사용 |
| 봉인 | 2 | AI 스토리에서 괴이 봉인 시도 | 조건부 사용 |

## 봉인 조건

- AI 스토리 모드에서만 선택 가능하다.
- 진명 조각 3개가 있어야 한다.
- 구체 방해 판정 규칙은 [[01_MVP/04_MVP_확정_필요_항목]]에서 확정한다.
