# 시간초과 규칙

## 기본 규칙

- 제한 시간은 기본 25초다.
- 시간 초과 시 기본 행동은 `침묵`이다.

## 시간초과 판정

1차 MVP AI 스토리는 서버 `deadline_at` 기준으로 시간초과를 판정한다.

브라우저 종료 또는 네트워크 끊김 자체는 즉시 시간초과로 보지 않는다.

서버 기준 시각이 `deadline_at`을 지났고 유효한 행동 제출이 없으면 시간초과로 처리한다.

재접속 또는 새로고침 후에는 서버의 최신 매치 상태를 조회한다.

## 반복 시간초과

| 누적 시간초과 | PvP | AI 스토리 |
|---:|---|---|
| 2회 | 이성 1 감소 | 저주 흔적 1 증가 |
| 3회 이상 | 항복 처리 | 괴이가 즉시 강한 패턴 사용 |

## 거울 속의 손님 강한 패턴

`거울 속의 손님`의 AI 스토리에서 누적 시간초과가 3회 이상이면 다음 괴이 행동은 `침묵`을 우선한다.

직전 괴이 행동이 이미 `침묵`이면 다음 괴이 행동은 `속임수`를 우선한다.

이 강한 패턴은 별도 특수 피해를 만들지 않는다.

수치 변화는 기존 상성 결과만 적용한다.

## PvP 분리

PvP의 reconnect, grace time, heartbeat, WebSocket 기반 연결 감지는 1차 MVP 구현 범위에서 제외한다.

상세 기준은 [[09_Approved_Contracts/21_AI_스토리_시간초과_판정_계약]]을 따른다.
