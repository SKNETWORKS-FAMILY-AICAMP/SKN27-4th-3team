# 확률 판정

MVP에서 확률은 제한적으로만 사용한다. 모든 확률은 서버에서 계산하고, seed와 결과를 로그에 저장한다.

## 허용된 확률 판정

| 판정 | 사용 위치 | 상태 |
|---|---|---|
| 저주 충돌 주사위 | `저주` vs `저주` | 확정 |
| 거짓 단서 판별 | `간파` vs `속임수` | 확정 |
| 괴이별 특수 패턴 발동 | 괴이 행동 정책 | 1차 MVP `거울 속의 손님`은 확률을 사용하지 않음 |

## 저주 충돌 주사위

- `저주` vs `저주`에서만 사용한다.
- 양쪽이 1d6을 굴린다.
- 양쪽은 기본으로 이성 -1을 받는다.
- 더 높은 숫자를 낸 쪽은 상대에게 추가 이성 -1을 적용한다.
- 숫자가 같으면 추가 피해는 발생하지 않는다.
- 주사위는 승패 전체를 결정하지 않고 피해량만 보정한다.

## 저주 충돌 저장값

- random_seed
- actor_roll
- target_roll
- actor_roll_sides
- target_roll_sides
- roll_winner
- additional_damage_applied

## 의심 보정

- `간파` vs `속임수`의 기본 성공률은 50%다.
- 의심 1당 다음 `간파` vs `속임수` 판정 성공률이 +10% 오른다.
- 의심은 최대 3까지 누적된다.
- 의심 보정 후 최종 성공률 상한은 80%다.
- 의심은 `간파` vs `속임수` 판정 후 0으로 초기화한다.

## 거짓 단서 판별

- `간파` vs `속임수`에서만 사용한다.
- 성공 시 이번 속임수를 차단한다.
- 성공 시 기존 거짓 단서가 있으면 1개 제거한다.
- 성공 시 기존 거짓 단서가 없으면 제거 없이 속임수 차단만 적용한다.
- 실패 시 거짓 단서 +1을 적용한다.
- 거짓 단서는 최대 3개까지 보유한다.

## 거짓 단서 판별 저장값

- random_seed
- base_success_rate
- suspicion_before
- suspicion_bonus
- final_success_rate
- roll_value
- insight_success
- false_clue_removed
- false_clue_added
- suspicion_after

## 미확정

- 주사위 결과를 공개 로그에 숫자로 직접 표시하는 UI 형식
