# 우물 밑의 목소리

## 구현 범위

- 문서 확정 대상이다.
- 1차 MVP 구현 대상은 아니다.

## 컨셉

잃어버린 사람의 목소리로 유혹하는 괴이.

## 금기

대답하면 안 되는 질문이 있다.

## 진명 조각

1. 우물 벽에 거꾸로 새겨진 성
2. 물 위에 뜨는 검은 머리카락
3. 대답하지 않은 질문의 원문

## 패턴

- 침묵을 자주 쓰는 플레이어에게 공포 누적
- 저주 위주 플레이어에게 수호 후 계약
- 속임수 위주 플레이어에게 간파 강화

## 문서 확정 전 필요 항목

- 브리핑 최종 문장
- 승리 후 기록 문장
- 패배 후 기록 문장
- 거짓 단서 2-4개
- 각 진명 조각의 reveal condition
- 각 거짓 단서의 trigger condition
