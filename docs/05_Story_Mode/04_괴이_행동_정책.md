# 괴이 행동 정책

## 원칙

- 괴이는 LLM이 자유롭게 행동하지 않는다.
- 서버가 계산한 스타일 지표를 기반으로 행동 가중치를 조정한다.
- MVP에서는 정해진 정책 안에서만 행동을 선택한다.

## 1차 MVP 승인 정책

1차 MVP 괴이 행동 정책은 [[09_Approved_Contracts/16_거울_속의_손님_괴이_행동_정책]]을 따른다.

`거울 속의 손님`은 결정적 가중치 기반으로 행동을 선택한다.

| 항목 | 확정값 |
|---|---|
| 기본 행동 가중치 | `속임수 25`, `침묵 25`, `간파 15`, `계약 15`, `저주 10`, `수호 10`, `봉인 0` |
| 스타일 반영 시작 | 3턴 완료 후 4턴째부터 |
| tie-break | `침묵 > 속임수 > 계약 > 간파 > 저주 > 수호` |
| 반복 방지 | 같은 괴이 행동 3턴 연속 선택 금지 |
| 시간초과 3회 이상 | `침묵` 우선. 직전 괴이 행동이 이미 `침묵`이면 `속임수` 우선 |

## 예시 대응

| 플레이어 성향 | 괴이 대응 |
|---|---|
| 간파 과다 | 속임수와 거짓 단서 증가 |
| 계약 과다 | 간파와 저주 카운터 증가 |
| 수호 과다 | 침묵, 계약, 턴 제한 압박 증가 |
| 저주 과다 | 수호 후 반격 패턴 증가 |
| 속임수 과다 | 간파 성공률 증가 |
| 늦은 선택 많음 | 시간 압박형 괴이 등장 |

## 미확정

- `우물 밑의 목소리`, `문밖의 어머니`의 괴이별 행동 정책
- 전체 7x7 상성표에서 `간파` vs `침묵`으로 공개되는 다음 행동 후보 2개 생성 방식
