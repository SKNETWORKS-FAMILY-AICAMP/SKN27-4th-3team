# 진명 조각과 단서

## 진명 조각

- AI 스토리 승리를 위해 3개를 확보해야 한다.
- 진명 조각 3개 확보 후 `봉인`을 시도할 수 있다.

## 거짓 단서

- 단서처럼 보이지만 봉인에 도움이 되지 않는다.
- `속임수` 또는 괴이 패턴으로 생성될 수 있다.

## 미확정

- 진짜 단서와 거짓 단서의 UI 표시 방식
- 단서가 진짜였는지 플레이어에게 즉시 알려줄지 여부
- `간파` 성공 시 진명 조각 획득 조건
