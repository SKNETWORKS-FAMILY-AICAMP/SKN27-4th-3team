# 거울 속의 손님 오너 확정 워크시트

이 문서는 `거울 속의 손님`의 공식 스토리 기준을 오너가 확정하기 위한 워크시트다.

현재 상태는 `approved`다. 이 문서는 `거울 속의 손님`의 공식 스토리 구현 기준으로 사용할 수 있다.

## 확정된 큰 틀

아래 항목은 기존 승인본을 따른다.

| 항목 | 확정값 |
|---|---|
| 1차 MVP 구현 괴이 | `거울 속의 손님` |
| 괴이 컨셉 | 거울을 통해 사람의 기억을 훔치는 괴이 |
| 금기 | 같은 질문을 두 번 반복하면 안 된다 |
| 금기 판정 방식 | 자유 텍스트가 아니라 `info_target_key` 반복 기반 |
| 진명 조각 수 | 3개 |
| 목표 | 진명 조각을 확보하고 봉인을 시도한다 |
| 서버 권위 | 단서 획득, 거짓 단서, 봉인, 승패는 서버가 결정한다 |
| LLM 권한 | 판정 이후 보조 문장, 요약, 변형 후보만 가능 |

## 승인된 정보 대상

| info_target_key | 의미 |
|---|---|
| `mirror_surface` | 거울 표면 |
| `mirror_back` | 깨진 거울 뒷면 |
| `missing_child_voice` | 사라진 아이의 목소리 |
| `forgotten_room` | 잊어버린 방 번호 |
| `self_reflection` | 플레이어의 비친 얼굴 |

## 공식 문장 입력

아래 문장은 오너가 직접 작성하거나 최종 승인한다.

### 사건 브리핑

status: `approved`

입력 기준:

- 사건 제목을 포함한다.
- `거울 속의 손님`이 어떤 위험인지 설명한다.
- 같은 질문 반복 금기를 플레이어가 이해할 수 있게 한다.
- 목표가 괴이를 죽이는 것이 아니라 진명을 파악하고 봉인하는 것임을 유지한다.

오너 입력:

```text
사건 파일 01. 거울 속의 손님.

오래된 방의 거울은 얼굴을 비추지 않는다.
그 안에는 잊힌 기억, 사라진 목소리, 그리고 네가 잃어버린 방 번호가 남아 있다.

같은 것을 두 번 묻지 마라.

첫 번째 대답은 단서일 수 있다.
두 번째 대답은 함정이다.

흩어진 진명 조각을 모아라.
이름을 완성하기 전에는, 거울 너머의 것을 봉인할 수 없다.
```

### 승리 기록

status: `approved`

입력 기준:

- 플레이어가 진명 조각을 모아 봉인에 성공했음을 기록한다.
- 괴이를 체력으로 처치했다는 표현을 피한다.
- 서버 판정 결과와 충돌하지 않는다.

오너 입력:

```text
사건 종료 기록.

흩어져 있던 세 조각의 이름이 하나로 이어졌다.
네가 완성한 진명은 거울 너머의 손님을 붙잡았고,
봉인의 문장이 닫히자 방 안의 모든 반사가 멈췄다.

거울은 깨지지 않았다.
하지만 더는 누구의 얼굴도 훔치지 않는다.

너는 이 사건에서 돌아왔다.
다만 마지막으로 비친 얼굴이 정말 너였는지는, 아직 확인되지 않았다.
```

### 패배 기록

status: `approved`

입력 기준:

- 플레이어가 의식에서 실패했음을 기록한다.
- 죽음, 실종, 기억 상실 등 최종 표현 수위는 오너가 결정한다.
- 서버 판정 결과와 충돌하지 않는다.

오너 입력:

```text
사건 종료 기록.

이름은 완성되지 못했다.
마지막 진명 조각은 거울 안쪽에서 멈췄고,
봉인의 문장은 끝까지 닫히지 않았다.

거울은 다시 얼굴을 비추기 시작했다.
하지만 그 안에서 고개를 든 것은 네가 아니었다.

사건 파일은 실종으로 보류된다.
방 안에는 아직도 같은 질문이 반복되고 있다.
```

### 결과 화면용 정적 요약

status: `approved`

입력 기준:

- LLM 요약 실패 시 표시할 수 있어야 한다.
- 승리/패배 양쪽에 대응할 수 있어야 한다.
- 공식 판정 결과처럼 과장하지 않는다.

오너 입력:

```text
승리 요약:
진명은 완성되었고, 거울 속의 손님은 봉인의 문장 안에 갇혔다.

패배 요약:
진명은 끝내 완성되지 못했고, 거울은 또 하나의 얼굴을 가져갔다.

중립 안내:
이 요약은 서버 판정 결과를 바탕으로 표시되는 정적 문장이다.
```

## 진명 조각 reveal condition 입력

진명 조각은 행동 상성 결과와 괴이별 조건을 함께 보고 서버가 최종 획득 여부를 결정한다.

아래 조건은 오너가 확정한다.

### 진명 조각 1

label: `깨진 거울의 뒷면에 남은 이름`

status: `approved`

오너 입력 항목:

| 항목 | 입력 |
|---|---|
| 주요 정보 대상 | `mirror_back` |
| 필요한 행동 또는 행동 결과 | `insight`로 `mirror_back`을 조사하고, 행동 결과가 단서 진척 후보를 만들면 획득한다. |
| 금기 위반 영향 | 해당 턴이 금기 위반이면 진명 조각을 획득하지 못하고 거짓 단서 후보가 생긴다. |
| 공개 문장 | 깨진 거울의 뒷면에서 지워지지 않은 획이 드러났다. 그것은 이름의 첫 조각이었다. |

### 진명 조각 2

label: `사라진 아이의 마지막 목소리`

status: `approved`

오너 입력 항목:

| 항목 | 입력 |
|---|---|

| 필요한 행동 또는 행동 결과 | `contract`로 `missing_child_voice`에 접근하고, 계약 결과가 진명 조각 또는 불완전한 진명 조각 진척을 만들면 획득한다. |
| 금기 위반 영향 | 해당 턴이 금기 위반이면 진명 조각을 획득하지 못하고 거짓 단서 후보가 생긴다. |
| 공개 문장 | 끊어진 목소리가 거울 안쪽에서 되돌아왔다. 마지막으로 불린 이름의 일부가 의식장에 남았다. |

### 진명 조각 3

label: `플레이어가 잊어버린 자기 방 번호`

status: `approved`

오너 입력 항목:

| 항목 | 입력 |
|---|---|
| 주요 정보 대상 | `forgotten_room` |
| 필요한 행동 또는 행동 결과 | 이미 진명 조각 2개를 확보한 뒤, `forgotten_room`을 대상으로 `insight` 또는 `contract`를 사용하고, 행동 결과가 단서 진척 후보를 만들면 획득한다. |
| 금기 위반 영향 | 해당 턴이 금기 위반이면 진명 조각을 획득하지 못하고 거짓 단서 후보가 생긴다. |
| 공개 문장 | 잊어버린 방 번호가 거울 표면에 잠시 떠올랐다. 마지막 조각은 네가 돌아가야 할 곳을 가리키고 있었다. |

아래 조건은 오너가 확정한다.

text: `거울을 깨면 끝난다.`

| trigger 조건 | `mirror_surface` 또는 `mirror_back`을 연속 조사해 금기 위반이 발생하거나, 해당 정보 대상에서 `속임수`가 성공하면 생성 후보가 된다. |

| 거짓으로 공개되는 조건 | `간파`가 해당 속임수 판별에 성공하면 서버가 이 단서를 거짓으로 공개하고 제거 또는 무효화한다. |

## 금기 세부 판정 입력

status: `approved`

현재 승인된 기준:

- 같은 정보 대상을 연속으로 조사하면 금기 위반 후보가 된다.
- 자유 텍스트 질문 유사도, LLM 판정, embedding 유사도, 단순 행동 반복은 MVP 금기 판정에 사용하지 않는다.

오너 확정:

| 항목 | 입력 |
|---|---|
| 연속 반복만 금기인지 여부 | 직전 정보 대상과 같은 `info_target_key`를 다시 조사한 경우만 금기 위반으로 본다. |
| 최근 N턴 내 반복도 금기인지 여부 | MVP에서는 최근 N턴 반복 판정을 사용하지 않는다. |
| 금기 위반이 항상 거짓 단서 후보를 만드는지 여부 | 금기 위반이 발생하면 항상 거짓 단서 생성 후보를 만든다. 확률은 사용하지 않는다. |
| 금기 위반 공개 로그 문장 | 같은 것을 다시 물었다. 거울 안쪽에서 돌아온 대답은 단서가 아니라 함정에 가까웠다. |

## 괴이 행동 정책 입력

status: `approved`

기존 방향:

- 플레이어가 `간파`를 자주 쓰면 `속임수` 빈도 증가
- 플레이어가 방어적이면 `침묵` 후 `계약` 사용
- 플레이어가 `계약`을 자주 쓰면 `간파` 카운터 사용

오너 확정:

| 항목 | 입력 |
|---|---|
| 기본 행동 가중치 | `속임수 25`, `침묵 25`, `간파 15`, `계약 15`, `저주 10`, `수호 10`, `봉인 0` |
| 스타일 반영 시작 | 3턴 완료 후 4턴째부터 적용한다. |
| 동일 가중치 tie-break | `침묵 > 속임수 > 계약 > 간파 > 저주 > 수호` |
| 반복 방지 | 같은 괴이 행동을 3턴 연속 선택하지 않는다. |
| `간파` 빈도 기준 | 최근 3턴 중 `간파` 2회 이상이면 `속임수 +20`, `저주 +5`를 적용한다. |
| 방어적 플레이 기준 | 최근 3턴 중 `수호` 또는 `침묵` 합계 2회 이상이면 `침묵 +15`, `계약 +15`를 적용한다. |
| `계약` 빈도 기준 | 최근 4턴 중 `계약` 2회 이상이면 `간파 +25`, `저주 +5`를 적용한다. |
| 시간초과 3회 이상 시 강한 패턴 효과 | 다음 괴이 행동은 `침묵`을 우선한다. 직전 괴이 행동이 이미 `침묵`이면 `속임수`를 우선한다. 별도 특수 피해는 만들지 않고 기존 상성 결과만 적용한다. |

## 프론트 전달 기준

프론트팀에는 오너 승인 전까지 아래 방식으로 전달한다.

- 이 문서는 공식 스토리 구현 기준이 아니라 오너 입력 워크시트다.
- 프론트팀은 화면 구조와 표현 후보를 제안할 수 있다.
- 프론트팀이 작성한 문장 후보는 오너 승인 전까지 공식 기준 문장이 아니다.
- 서버 판정과 충돌하는 문구는 사용할 수 없다.

## 승인 완료 조건

이 문서의 오너 결정 항목은 모두 확정됐다.

구현 시 세부 기준은 관련 승인본 문서를 함께 따른다.
