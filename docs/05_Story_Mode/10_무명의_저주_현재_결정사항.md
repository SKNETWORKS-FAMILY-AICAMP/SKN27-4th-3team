# 무명의 저주 현재 결정사항

이 문서는 PDF 원문 정리 이후 사용자가 추가로 확정한 최신 결정사항을 기록한다.

## 확정

| 항목 | 결정 |
|---|---|
| 주인공 이름 | 고정 이름을 쓰지 않는다. 플레이어가 직접 정한다. |
| 기존 PDF 이름 `이안` | 공식 고정 주인공명이 아니라 초안/예시 이름으로 취급한다. |
| 피티 | `거울 속의 손님`의 정체/진명으로 사용한다. |
| 표현 수위 | B안, 중간 수위의 심리 공포형으로 진행한다. |
| 공포 표현 기준 | 직접적인 잔혹 묘사보다 시선, 소리, 기억, 거울 반응, 자기 인식 붕괴 같은 암시형 표현을 우선한다. |

## 구현 반영 기준

- 백엔드, LLM, 정적 결과 문구에는 `이안`을 고정 주인공명으로 넣지 않는다.
- 플레이어를 지칭해야 할 때는 세션/프로필 nickname 또는 플레이어 입력명을 사용한다.
- LLM fallback 문구와 결과 문구는 피티를 `거울 속의 손님`의 이름으로 다룬다.
- B안 수위에서는 성적/신체 훼손 중심의 직접 묘사를 쓰지 않는다.
- PDF의 높은 수위 장면은 세계관 배경 참고로만 사용하고, 1차 MVP 화면 문구에는 완화해 반영한다.

## 아직 별도 결정이 필요한 항목

- `무명의 저주`를 기존 1차 MVP 사건 `거울 속의 손님`에 통합할지, 별도 사건으로 만들지 결정해야 한다.
- 피티의 진명 조각 3개를 현재 official enum에 맞춰 교체할지 결정해야 한다.
- 프롤로그 8개 장면 중 실제 플레이어에게 노출할 범위는 아직 확정되지 않았다.
- `무명의 저주` 전용 case_id, apparition_id, stage_id는 아직 확정되지 않았다.
