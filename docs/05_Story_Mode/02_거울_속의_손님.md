# 거울 속의 손님

## 컨셉

거울을 통해 사람의 기억을 훔치는 괴이.

## 금기

같은 질문을 두 번 반복하면 안 된다.

## 진명 조각

1. 깨진 거울의 뒷면에 남은 이름
2. 사라진 아이의 마지막 목소리
3. 플레이어가 잊어버린 자기 방 번호

## 진명 조각 reveal condition

진명 조각은 서버가 최종 획득 여부를 결정한다.

공통 기준:

- `insight`, `contract`만 진명 조각 reveal 후보를 만든다.
- `seal`은 정보 행동이지만 reveal 후보를 만들지 않고 최종 봉인 시도에만 사용한다.
- 같은 `info_target_key`를 연속 조사해 금기 위반이 발생한 턴에는 진명 조각을 획득하지 못한다.
- 금기 위반 턴에는 진명 조각 대신 거짓 단서 후보가 생긴다.

| 진명 조각 | 주요 정보 대상 | 필요한 행동 또는 행동 결과 | 공개 문장 |
|---|---|---|---|
| 깨진 거울의 뒷면에 남은 이름 | `mirror_back` | `insight`로 `mirror_back`을 조사하고, 행동 결과가 단서 진척 후보를 만들면 획득한다. | 깨진 거울의 뒷면에서 지워지지 않은 획이 드러났다. 그것은 이름의 첫 조각이었다. |
| 사라진 아이의 마지막 목소리 | `missing_child_voice` | `contract`로 `missing_child_voice`에 접근하고, 계약 결과가 진명 조각 또는 불완전한 진명 조각 진척을 만들면 획득한다. | 끊어진 목소리가 거울 안쪽에서 되돌아왔다. 마지막으로 불린 이름의 일부가 의식장에 남았다. |
| 플레이어가 잊어버린 자기 방 번호 | `forgotten_room` | 이미 진명 조각 2개를 확보한 뒤, `forgotten_room`을 대상으로 `insight` 또는 `contract`를 사용하고, 행동 결과가 단서 진척 후보를 만들면 획득한다. | 잊어버린 방 번호가 거울 표면에 잠시 떠올랐다. 마지막 조각은 네가 돌아가야 할 곳을 가리키고 있었다. |

## 거짓 단서

- 거울을 깨면 끝난다.
- 불을 끄면 안전하다.
- 이름을 부르면 괴이가 약해진다.

## 거짓 단서 trigger condition

거짓 단서는 서버가 최종 생성 여부를 결정한다.

공통 기준:

- 거짓 단서 생성은 `info_target_key` 기반으로 결정한다.
- 금기 위반은 직전 정보 대상과 같은 `info_target_key`를 다시 조사한 경우만 적용한다.
- 최근 N턴 반복, 자유 텍스트 유사도, LLM 판정, embedding 유사도는 MVP 금기 판정에 사용하지 않는다.
- 금기 위반이 발생하면 항상 거짓 단서 생성 후보를 만든다.
- 같은 거짓 단서는 중복 보유하지 않는다.
- 거짓 단서는 처음에는 거짓이라고 표시하지 않고, 서버가 거짓으로 공개한 뒤에만 거짓 단서로 표시한다.

| 거짓 단서 | trigger 조건 | 관련 정보 대상 | 거짓으로 공개되는 조건 |
|---|---|---|---|
| 거울을 깨면 끝난다. | `mirror_surface` 또는 `mirror_back`을 연속 조사해 금기 위반이 발생하거나, 해당 정보 대상에서 `속임수`가 성공하면 생성 후보가 된다. | `mirror_surface`, `mirror_back` | `간파`가 해당 속임수 판별에 성공하면 서버가 이 단서를 거짓으로 공개하고 제거 또는 무효화한다. |
| 불을 끄면 안전하다. | `missing_child_voice`를 연속 조사해 금기 위반이 발생하거나, 해당 정보 대상에서 `속임수`가 성공하면 생성 후보가 된다. | `missing_child_voice` | `간파`가 해당 속임수 판별에 성공하면 서버가 이 단서를 거짓으로 공개하고 제거 또는 무효화한다. |
| 이름을 부르면 괴이가 약해진다. | 진명 조각을 2개 이상 보유한 뒤 `forgotten_room` 또는 `self_reflection`에서 금기 위반이 발생하거나 `속임수`가 성공하면 생성 후보가 된다. | `forgotten_room`, `self_reflection` | `간파`가 해당 속임수 판별에 성공하면 서버가 이 단서를 거짓으로 공개하고 제거 또는 무효화한다. |

## 확정된 공식 문장

### 사건 브리핑

```text
사건 파일 01. 거울 속의 손님.

오래된 방의 거울은 얼굴을 비추지 않는다.
그 안에는 잊힌 기억, 사라진 목소리, 그리고 네가 잃어버린 방 번호가 남아 있다.

같은 것을 두 번 묻지 마라.

첫 번째 대답은 단서일 수 있다.
두 번째 대답은 함정이다.

흩어진 진명 조각을 모아라.
이름을 완성하기 전에는, 거울 너머의 것을 봉인할 수 없다.
```

### 승리 기록

```text
사건 종료 기록.

흩어져 있던 세 조각의 이름이 하나로 이어졌다.
네가 완성한 진명은 거울 너머의 손님을 붙잡았고,
봉인의 문장이 닫히자 방 안의 모든 반사가 멈췄다.

거울은 깨지지 않았다.
하지만 더는 누구의 얼굴도 훔치지 않는다.

너는 이 사건에서 돌아왔다.
다만 마지막으로 비친 얼굴이 정말 너였는지는, 아직 확인되지 않았다.
```

### 패배 기록

```text
사건 종료 기록.

이름은 완성되지 못했다.
마지막 진명 조각은 거울 안쪽에서 멈췄고,
봉인의 문장은 끝까지 닫히지 않았다.

거울은 다시 얼굴을 비추기 시작했다.
하지만 그 안에서 고개를 든 것은 네가 아니었다.

사건 파일은 실종으로 보류된다.
방 안에는 아직도 같은 질문이 반복되고 있다.
```

### 결과 화면 정적 요약

```text
승리 요약:
진명은 완성되었고, 거울 속의 손님은 봉인의 문장 안에 갇혔다.

패배 요약:
진명은 끝내 완성되지 못했고, 거울은 또 하나의 얼굴을 가져갔다.

중립 안내:
이 요약은 서버 판정 결과를 바탕으로 표시되는 정적 문장이다.
```

## 괴이 행동 정책

`거울 속의 손님`은 결정적 가중치 기반으로 괴이 행동을 선택한다.

기준은 [[09_Approved_Contracts/16_거울_속의_손님_괴이_행동_정책]]을 따른다.

| 항목 | 확정값 |
|---|---|
| 기본 행동 가중치 | `속임수 25`, `침묵 25`, `간파 15`, `계약 15`, `저주 10`, `수호 10`, `봉인 0` |
| 스타일 반영 시작 | 3턴 완료 후 4턴째부터 |
| tie-break | `침묵 > 속임수 > 계약 > 간파 > 저주 > 수호` |
| 반복 방지 | 같은 괴이 행동 3턴 연속 선택 금지 |
| `간파` 과다 대응 | 최근 3턴 중 `간파` 2회 이상이면 `속임수 +20`, `저주 +5` |
| 방어적 플레이 대응 | 최근 3턴 중 `수호` 또는 `침묵` 합계 2회 이상이면 `침묵 +15`, `계약 +15` |
| `계약` 과다 대응 | 최근 4턴 중 `계약` 2회 이상이면 `간파 +25`, `저주 +5` |
| 시간초과 3회 이상 | 다음 괴이 행동은 `침묵` 우선. 직전 괴이 행동이 이미 `침묵`이면 `속임수` 우선 |
