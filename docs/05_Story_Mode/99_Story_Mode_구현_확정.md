# Story Mode 구현 확정

이 문서는 AI 스토리 구현 착수 전 승인받는 최종 기준 문서다.

## 확정 전 조건

- 1차 MVP 기본 사건은 `거울 속의 손님`이다.
- 후속 백엔드 사건 seed로 `무명(無名)의 저주`를 별도 사건으로 추가한다.
