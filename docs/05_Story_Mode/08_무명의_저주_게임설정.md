# 무명(無名)의 저주 게임 설정

## 시대와 공간

| 구분 | 설정 |
|---|---|
| 소녀의 시대 | 19세기 말 빅토리아풍 고딕 호러 시대 |
| 주인공의 시대 | 21세기 현대사회 |
| 주요 지역 | 도심 외곽 구시가지 `침묵의 골짜기` |
| 주요 장소 | 안개가 걷히지 않는 외곽의 낡은 저택 |
| 핵심 공간 | 지하실, 다락방, 안방의 거대한 은도금 거울, 주인공의 방과 화장실 |

소녀의 비극은 연금술과 주술이 음지에서 성행하던 19세기 말 저택에서 시작된다.

현대의 주인공은 트라우마를 피해 외곽의 낡은 저택으로 이사하지만, 그 저택은 과거 소녀가 감금되고 매장된 장소다.

## 저주의 발생

가문은 추악한 수치와 비밀을 은폐하기 위해 소녀를 지하실에 감금했다.

소녀는 이름조차 불리지 못한 채 부모의 매질과 방관 속에 살았고, 결국 저주를 두려워한 부모에 의해 지하실 벽 속에 산 채로 매장된다.

단 한 번도 불리지 못한 이름과 빛을 보지 못한 억울함은 소녀의 영혼을 가문을 파멸시키는 악귀로 뒤틀리게 한다.

## 봉인과 진실의 거울

가주는 원혼의 분노를 억누르기 위해 연금술사와 주술사를 불러 저택 자체를 거대한 결계로 개조했다.

안방에는 인간의 육신과 거짓을 투과해 영혼의 본질을 비추는 거대한 은도금 거울이 설치된다.

PDF는 이 거울을 저주를 억누르는 장치이자, 원혼의 본래 형상을 드러내는 핵심 도구로 설정한다.

## 주인공 이안

| 항목 | 설정 |
|---|---|
| 이름 | 이안 |
| 나이 | 17-19세 |
| 외형 | 왜소한 체구, 창백한 안색, 피로한 상태 |
| 배경 | 유년 시절 지하실에 갇혀 아버지에게 학대당함 |
| 현재 상태 | 가위눌림, 이명, 불안, 신경안정제 의존 |

이안은 선량한 본성을 가졌지만, 유년 시절의 학대로 인해 극도의 불안과 공포 속에 산다.

본래의 자아를 보호하기 위해 분노와 증오만을 표출하는 `텅 빈 제2의 자아`가 분열되었고, 이 정신적 공백이 피티의 빙의 통로가 된다.

## 피티

| 항목 | 설정 |
|---|---|
| 이름 | 피티 |
| 나이 | 13-15세, 시나리오상 약 15세 |
| 체구 | 앙상하게 마른 소녀 |
| 외형 | 피멍, 까진 피부, 흙먼지 묻은 맨발, 피와 오물로 엉킨 머리카락 |
| 상징 | 무명실로 꿰매어진 입술 |
| 본성 | 여리고 겁 많은 상처받은 아이 |
| 악귀화 조건 | 자신과 같은 고통을 주는 학대범을 마주할 때 뒤틀린 분노가 폭발함 |

피티는 단순한 처치 대상이 아니라, 이름과 목소리를 빼앗긴 상처받은 원혼이다.

학대범을 보면 잔혹한 악귀로 돌변하지만, 핵심 결말 방향은 처치가 아니라 진명을 불러 해방하는 구조다.

## 빙의 구조

빙의는 이안의 정신적 공백과 피티의 원한이 공명하면서 발생한다.

이안이 고용량 신경안정제를 먹고 깊은 무의식에 빠지면 영혼의 방어벽이 무너진다.

이때 이안이 만들어낸 분노의 빈 인격이 저택에 남은 피티의 원한과 공명하고, 피티는 이안의 육신을 `껍데기`처럼 사용한다.

빙의 이후 피티는 밤마다 이안의 몸으로 아동 학대범들을 찾아가 잔혹한 사적 제재를 가한다.

## 상징 오브젝트

| 오브젝트 | 역할 |
|---|---|
| 낡은 곰 인형 | 밤사이 벌어진 사건을 주인공에게 인지시키는 전리품 |
| 가죽 장정 일기장 | 가문의 범죄, 진실의 거울 사용법, 진짜 이름 단서를 담은 기록 |
| 진실의 거울 | 영혼의 본질을 비추고 원혼의 본래 형상을 드러내는 장치 |
| 무명실 | 이름과 목소리를 빼앗긴 피티의 상징 |
| 침묵의 골짜기 저택 | 과거의 죄와 현재의 트라우마가 겹치는 저주의 공간 |

## 플레이 시작점

게임은 플레이어가 어둡고 음습한 방의 침대에서 눈을 뜨는 장면으로 시작한다.

방 안에는 창문 틈으로 안개가 스며들고, 침대 발치에는 피 묻은 낡은 곰 인형이 놓여 있다.

배경음은 둔탁한 심장 박동에서 시계 초침 소리로 넘어가며, 비릿한 쇠 냄새와 손아귀의 저림이 밤사이 벌어진 일을 암시한다.

첫 동선은 방과 연결된 화장실 거울이다.

거울 속 주인공 얼굴에는 본인의 의지와 무관한 잔혹한 미소가 걸리고, 플레이어는 자신의 육체가 밤사이 침식당했음을 인지한 채 탐색을 시작한다.

## 저주 해소 조건

저주를 끊기 위해서는 자정에 저택의 안방에 걸린 은도금 거울 앞에 서야 한다.

거울이 피티의 본래 형상을 드러냈을 때, 플레이어는 그녀의 두 눈을 마주하고 가문의 기록에서 지워진 진짜 이름을 불러야 한다.

PDF 기준 진명은 `피티`로 정리되어 있다.

이름을 되찾은 영혼은 괴물의 형상에서 해방되고 이승의 사슬에서 벗어난다.

## 후속 결정 필요

- `무명(無名)의 저주`를 `거울 속의 손님`과 통합할지, 별도 사건으로 둘지 결정해야 한다.
- PDF의 주인공명 `이안`을 그대로 사용할지, 로그인 유저 닉네임으로 치환할지 결정해야 한다.
- PDF 기준 진명 `피티`는 [[09_Approved_Contracts/26_무명의_저주_사건_계약]]에서 공식 진명으로 확정했다.
- 기존 LLM 참고 문서에 남아 있던 `엘리자베스`는 현재 공식 설정에서 사용하지 않는다.
- `진실의 거울`과 기존 `거울 속의 손님`의 거울 설정을 병합할 수 있는지 검토해야 한다.
- 피티의 사적 제재 설정은 수위가 높으므로 1차 MVP 표현 수위와 청소년 이용 가능 범위를 별도로 결정해야 한다.
