# 백엔드 앱 경계

| 앱 | 책임 | MVP |
|---|---|---|
| accounts | 회원가입, 로그인, JWT, refresh rotation, 비밀번호 재설정, 인증 이벤트 | 포함 |
| profiles | 닉네임, 전적 요약, 공개 프로필 | 포함 |
| game_rules | 행동, 자원, 상성, 승패 조건의 결정적 규칙 | 포함 |
| matches | 매치, 참가자, 턴, 행동 제출, 결과 스냅샷 | 포함 |
| story | AI 스토리 스테이지, 괴이, 사건 진행도 | 포함 |
| ai_profile | 플레이어 스타일 지표 계산과 저장 | 포함 |
| knowledge | KAG 노드와 관계 관리 | 제외 |
| retrieval | RAG 문서, 청크, embedding, 검색, query log | 포함 |
| llm | LLM provider adapter, 프롬프트 템플릿, 생성 로그 | 제외 |
| audit | 보안 이벤트, 부정행위 의심 로그, 운영 로그 | 제외 |

## 핵심 원칙

- `game_rules`는 순수 함수 중심으로 둔다.
- `matches`는 `game_rules`의 결과를 저장한다.
- `matches`는 AI 스토리 단일 플레이 기준으로 설계한다.
- `llm`은 `game_rules`를 호출하거나 수정하지 않는다.
- `retrieval`은 구현 준비 범위에 포함하지만 판정에 관여하지 않는다.
- RAG 검색 결과는 룰, 승패, 인증, 권한, 진명 조각, 거짓 단서, 괴이 행동 선택을 바꾸지 않는다.
- 상세 기준은 [[09_Approved_Contracts/17_백엔드_RAG_AI_Profile_구현_계약]]을 따른다.
- PvP 미사용 기준은 [[09_Approved_Contracts/19_PvP_미사용_및_구조_정리_계약]]을 따른다.
