# AI 스토리 진행

## 대상 테이블 초안

| 테이블 | 주요 필드 |
|---|---|
| story_cases | id, title, summary, difficulty, status |
| apparitions | id, name, category, description, taboo, base_policy_json |
| stages | id, case_id, apparition_id, order, victory_condition_json |
| true_name_fragments | id, apparition_id, label, content, reveal_condition_json |
| false_clues | id, apparition_id, content, trigger_condition_json |
| player_story_progress | id, user_id, stage_id, status, attempts, completed_at |

## MVP 방향

- 첫 사건은 `거울 속의 손님`으로 제한한다.
- 스테이지 진행도는 사용자별로 저장한다.
- 진명 조각과 거짓 단서는 서버 데이터로 관리한다.
- 공식 브리핑, 승리 기록, 패배 기록, 결과 화면 정적 요약은 [[05_Story_Mode/02_거울_속의_손님]]을 따른다.
- 진명 조각 reveal condition은 [[09_Approved_Contracts/03_진명_조각_획득_기준]]을 따른다.
- 거짓 단서 trigger condition은 [[09_Approved_Contracts/04_거짓_단서_생성_기준]]을 따른다.
- 금기 판정은 [[09_Approved_Contracts/12_거울_속의_손님_금기_정의]]를 따른다.
- 괴이 행동 정책은 [[09_Approved_Contracts/16_거울_속의_손님_괴이_행동_정책]]을 따른다.
- JSONField payload에는 `schema_version`을 포함하고 Python `jsonschema`로 검증한다.
