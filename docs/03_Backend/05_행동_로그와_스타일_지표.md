# 행동 로그와 스타일 지표

## 저장할 행동 이벤트

행동 이벤트는 턴 resolve 시점에 저장한다.

| 필드 | 설명 |
|---|---|
| user_id | 행동한 사용자 ID |
| mode | 매치 모드 |
| match_id | 매치 ID |
| stage_id | 스테이지 ID |
| turn_number | 턴 번호 |
| action_code | 선택 행동 |
| info_target_key | 정보 대상. 없으면 nullable |
| decision_duration_ms | 선택까지 걸린 시간 |
| sanity_before | 선택 당시 이성 |
| ritual_power_before | 선택 당시 의식력 |
| curse_marks_before | 선택 당시 저주 흔적 |
| opponent_action_code | 상대 행동 |
| result_code | 턴 결과 코드 |
| acquired_clue_id | 획득 단서. 없으면 nullable |
| clue_truth_state | 단서가 진짜였는지 여부 |
| match_outcome | 승패. 매치 종료 전이면 nullable |

## 스타일 지표

스타일 지표는 각 턴 resolve 직후 계산한다.

매치 종료 시 최종 재계산을 수행한다.

분모가 0인 지표는 `0.0`으로 저장한다.

| 지표 | 계산 방식 |
|---|---|
| 공격성 | 저주 선택 수 / 전체 턴 수 |
| 방어성 | 수호 선택 수 / 전체 턴 수 |
| 정보 집착 | 간파 선택 수 / 전체 턴 수 |
| 기만성 | 속임수 선택 수 / 전체 턴 수 |
| 위험 선호 | 계약 선택 수 / 전체 턴 수 |
| 침묵 의존 | 침묵 선택 수 / 전체 턴 수 |
| 위기 방어율 | 이성 4 이하에서 수호 선택 수 / 위기 턴 수 |
| 위기 계약율 | 이성 4 이하에서 계약 선택 수 / 위기 턴 수 |
| 늦은 선택률 | 제한 시간 70% 이후 제출 수 / 전체 턴 수 |

## 개인정보 삭제

개인정보 삭제 시 기본 정책은 행동 이벤트와 스타일 스냅샷 삭제다.

전적 요약은 사용자 삭제 정책에 맞춰 삭제 또는 익명화한다.

상세 기준은 [[09_Approved_Contracts/17_백엔드_RAG_AI_Profile_구현_계약]]을 따른다.
