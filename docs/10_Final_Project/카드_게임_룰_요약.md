# 카드 게임 룰 요약

이 문서는 발표와 README 연결을 위한 요약본이다. 상세 판정 기준은 승인된 게임 룰 문서와 백엔드 룰 엔진을 기준으로 한다.

## 게임 개요

- 장르: 초자연 공포 스릴러 미스터리 기반 1대1 턴제 심리전
- 플레이 목표: 괴이의 진명을 추적하고 조건을 만족한 뒤 `봉인`으로 결전을 끝낸다.
- 판정 권위: 서버의 룰 엔진이 턴 결과와 승패를 최종 결정한다.
- LLM/RAG 역할: 문장 보조와 근거 검색용이며, 룰/승패/단서/진명/괴이 행동을 결정하지 않는다.

## 기본 자원

| 자원/상태 | 시작값 | 범위 | 의미 |
|---|---:|---:|---|
| 이성 | 12 | 0-12 | 0이 되면 패배한다. |
| 의식력 | 3 | 0-5 | 행동 비용으로 사용한다. |
| 저주 흔적 | 0 | 0-5 | 5에 도달하면 패배 조건이 된다. |
| 진명 조각 | 0 | 0-3 | 결전 조건을 여는 핵심 정보다. |
| 불완전한 진명 조각 | 0 | 0-1 | 2개 누적 시 진명 조각 1개로 전환된다. |
| 의심 | 0 | 0-3 | `간파`와 `속임수` 상호작용의 보정 상태다. |
| 거짓 단서 | 0 | 0-3 | 플레이어 판단을 흐리는 가짜 정보다. |
| 보호막 | 0 | 0-1 | 다음 저주 피해 2를 막고 소모된다. |

## 행동 카드

| 행동 | 비용 | 역할 | 요약 |
|---|---:|---|---|
| 저주 | 2 | 공격 | 상대 이성을 깎고 계약/봉인을 방해한다. |
| 수호 | 1 | 방어 | 저주 피해를 막고 보호막을 만든다. |
| 간파 | 1 | 정보 | 상대 행동과 단서를 파악하며 진명 진행에 기여한다. |
| 속임수 | 1 | 기만 | 거짓 단서를 만들고 간파/계약/봉인을 흔든다. |
| 침묵 | 0 | 준비 | 의식력을 회복하거나 다음 행동의 정보를 일부 드러낸다. |
| 계약 | 3 | 고위험 정보 획득 | 성공하면 진명 진행에 크게 기여하지만 실패 시 저주 흔적이 쌓인다. |
| 봉인 | 2 | 결전 | 진명 조건을 만족한 뒤 사용하는 최종 행동이다. |

## 턴 진행

1. 서버가 현재 턴과 deadline을 만든다.
2. 플레이어가 사용 가능한 행동 중 하나를 선택한다.
3. 서버는 참가자 권한, 현재 턴, 중복 제출 nonce, 행동 가능 여부, 의식력 비용, deadline을 검증한다.
4. 괴이 행동과 플레이어 행동을 동시에 공개한다.
5. 7x7 상성표 기준으로 자원/상태/로그를 적용한다.
6. 승패 조건을 확인한다.
7. 종료 조건이 없으면 다음 턴으로 넘어간다.

## 주요 상성

| 조합 | 핵심 결과 |
|---|---|
| 저주 vs 수호 | 저주 피해가 막히고 수호 쪽에 보호막이 생긴다. |
| 저주 vs 간파 | 간파 쪽이 피해를 받고 단서 획득에 실패한다. |
| 간파 vs 속임수 | 확률 판정과 의심 보정에 따라 속임수 차단 또는 거짓 단서 증가가 발생한다. |
| 속임수 vs 봉인 | 봉인 방해 단계가 크게 올라 봉인이 실패한다. |
| 계약 vs 침묵 | 계약이 성공해 진명 조각 후보 또는 비밀 노출을 얻는다. |
| 계약 vs 속임수 | 계약이 실패하고 저주 흔적 또는 거짓 단서가 증가한다. |
| 봉인 vs 수호 | 방해 단계가 낮아 조건이 맞으면 봉인이 성공할 수 있다. |

봉인 방해 단계는 상대 행동에 따라 다르다.

| 상대 행동 | 봉인 방해 단계 |
|---|---:|
| 속임수 | +2 |
| 계약 | +2 |
| 저주 | +1 |
| 간파 | +1 |
| 침묵 | +1 |
| 수호 | +0 |

## 승패 조건

| 결과 | 조건 |
|---|---|
| 승리 | 진명 조건을 만족하고 봉인에 성공한다. |
| 패배 | 이성이 0이 된다. |
| 패배 | 저주 흔적이 최대치에 도달한다. |
| 패배 | 12턴 안에 결전에 성공하지 못한다. |

동일 턴에 승리와 패배 조건이 함께 발생하면 `봉인 성공`이 우선한다. 봉인 성공이 없고 이성/저주 흔적 패배 조건이 발생하면 패배한다. 12턴 종료 시점에도 봉인 성공이 없으면 패배한다.

## 사건별 결전 기준

| 사건 | 결전 조건 | 설명 |
|---|---|---|
| `mirror_guest` | 진명 조각 3개 | 괴이의 진명을 충분히 확보한 뒤 봉인을 시도한다. |
| `nameless_curse` | 진명 조각 2개 이상 | 피티의 이름을 되찾는 결전이다. 처치가 아니라 회복이 목적이다. |
