# LLM 경계 기준

LLM은 서버 판정 이후의 보조 문장 생성에만 사용한다.

## 사용할 수 있는 입력

- 서버가 확정한 승패 결과
- 서버가 확정한 종료 사유
- 서버가 계산한 스타일 지표
- 서버가 저장한 턴 로그
- 승인된 공식 문장과 fallback 문장
- RAG 검색 결과의 문서 ID, chunk ID 같은 근거 참조

## 사용할 수 없는 역할

- 행동 성공/실패 판단
- 승패 판단
- 자원 수치 계산
- 진명 조각 획득 판단
- 거짓 단서 생성 또는 진위 판단
- 괴이 행동 선택
- 보상, 랭킹, 매칭 판단
- 공식 설정 추가

## 실패 처리

LLM 생성이 실패해도 결과 화면은 서버 판정과 정적 fallback 문장으로 완성되어야 한다.

LLM 결과는 공식 룰, 공식 설정, 서버 판정으로 취급하지 않는다.
