# 데모 스토리 참고: 무명(無名)의 저주

이 문서는 `game_scenario_the_nameless_curse.pdf`를 바탕으로 정리한 데모 스토리 참고 문서다.

현재 이 내용은 공식 확정본이 아니다. 다만 향후 본 스토리 구성 후보로 사용할 가능성이 높으며, 세부 설정과 문장은 수정될 수 있다.

PDF 초고의 주인공 이름은 `이안`이지만, 실제 게임에서는 로그인한 유저의 닉네임을 주인공명으로 사용한다.

현재 `nameless_curse`에서 공식 괴이 표시명과 진명은 `피티`다.

LLM은 이 문서를 공식 판정, 공식 룰, 확정 스토리 문장으로 취급하지 않는다.

## 문서 용도

- 데모 스토리의 분위기와 핵심 구조를 이해한다.
- LLM 결과 요약과 스타일 요약의 톤 참고 자료로 사용한다.
- 향후 스토리 확정 문서가 나오기 전까지 본 스토리 후보 레퍼런스로만 사용한다.

## 주요 인물

### 주인공

유년 시절 학대 트라우마를 가진 청년이다.

선량한 본성을 지녔지만 밤마다 기억을 잃고, 자신의 몸이 알 수 없는 폭력의 흔적을 남기는 상황에 놓인다.

주인공의 상처와 분노는 괴이가 파고들 수 있는 빈틈이 된다.

실제 게임에서는 로그인한 유저의 닉네임을 주인공명으로 사용한다.

PDF 초고에서는 주인공이 `이안`으로 표기되어 있다.

### 피티

`nameless_curse`의 공식 괴이 표시명과 진명이다.

PDF 초고의 원혼명 `엘리자베스`는 현재 공식 설정에서 사용하지 않는다.

괴이는 19세기 말 학대당한 채 저택 벽 속에 매장된 소녀의 원혼 설정을 기반으로 한다.

자신의 이름을 불리지 못한 채 죽었고, 주인공의 뒤틀린 분노 인격에 빙의해 학대범들을 사냥한다.

시나리오 후반부에서는 잔혹한 괴물이라기보다 이름과 자아를 빼앗긴 상처받은 영혼으로 드러난다.

## 시나리오 흐름

### S#1. 적막한 아침, 비릿한 각성

주인공은 피 냄새와 근육통 속에서 깨어난다.

침대 발치에는 아동 학대범의 집에서 발견되었다던 피 묻은 곰 인형이 놓여 있다.

주인공은 자신이 움직이지 않았다고 믿지만, 손은 낯선 다정함으로 인형을 쓰다듬는다.

머릿속에는 자신의 생각인지 환청인지 모를 만족감이 피어오른다.

핵심 기능:

- 기억 상실
- 자기 몸에 대한 통제 상실
- 죄책감과 낯선 만족감의 충돌

### S#2. 다락방의 먼지, 그리고 거울의 전설

주인공은 저주가 시작된 원인을 찾기 위해 저택을 뒤진다.

다락방에서 낡은 일기장 `잊혀진 가문의 기록: 벽 속의 아이들`을 발견한다.

기록에는 가문의 수치를 덮기 위해 아이가 지하실에 갇히고, 결국 벽 속에 묻혔다는 내용이 적혀 있다.

주인공은 자신의 유년 시절 학대 경험과 벽 속 아이의 고통이 서로 닮아 있음을 깨닫는다.

일기장에는 저주를 끊을 방법으로 `진실의 거울`이 언급된다.

핵심 기능:

- 과거 기록 조사
- 원혼의 사연 발견
- 주인공 트라우마와 원혼의 고통 연결
- 진실의 거울 단서 획득

### S#3. 진실의 거울 앞, 두 자아의 충돌

자정이 가까워지자 주인공은 안방의 거대한 은도금 거울 앞에 선다.

거울은 인간의 육신과 거짓을 투과해 영혼의 본질을 비추는 힘을 가진다.

괴이는 주인공에게 자신들이 같은 고통을 겪었으며, 자신이 학대범들을 처단했다고 주장한다.

거울 속 주인공의 형상은 15살 남짓한 소녀의 모습으로 변한다.

그 소녀는 앙상한 몸, 흙먼지 묻은 맨발, 무명실로 꿰매어진 입술을 가진다.

주인공은 괴이의 고통을 인정하면서도 살인이 구원이 아니라고 맞선다.

핵심 기능:

- 거울 앞 대면
- 내면의 분노와 원혼의 논리 충돌
- 원혼의 진짜 형상 공개
- 진명 추리의 압박

### S#4. 해방, 그리고 고요한 아침

주인공은 일기장의 단서를 조합해 괴이의 진짜 이름을 부른다.

PDF 초고에서는 그 이름이 `엘리자베스`였으나, 현재 공식 진명은 `피티`다.

이름을 들은 괴이는 괴물이 아니라 상처받은 아이의 모습으로 돌아온다.

입술을 묶던 무명실은 재가 되어 흩어지고, 괴이는 해방된다.

거울은 산산조각 나고, 주인공은 아침 햇살 속에서 자신의 얼굴을 되찾는다.

핵심 기능:

- 진명 호명
- 원혼 해방
- 거울 파괴
- 자기 얼굴과 자아 회복

## 핵심 소재

| 소재 | 의미 |
|---|---|
| 피 묻은 곰 인형 | 기억 상실과 밤의 폭력 흔적 |
| 낡은 저택 | 과거의 죄와 현재의 트라우마가 겹치는 공간 |
| 다락방 일기장 | 원혼의 사연과 해결법을 담은 기록 |
| 진실의 거울 | 영혼의 본질을 드러내는 장치 |
| 무명실로 꿰매어진 입 | 이름과 목소리를 빼앗긴 원혼의 상징 |
| 진명 | 원혼을 괴물에서 인간으로 되돌리는 핵심 열쇠 |
| 깨진 거울 | 저주 해소와 자아 회복의 증거 |

## LLM 톤 참고

이 시나리오의 문체는 아래 방향을 따른다.

- 어둡고 습한 고딕 호러 분위기
- 감각 묘사 중심의 심리 공포
- 피, 금속 냄새, 거울, 침묵, 먼지 같은 구체적 이미지
- 괴이를 단순한 적이 아니라 상처와 분노의 잔재로 다룸
- 결말은 처치가 아니라 해방과 회복에 가까움

LLM 요약에 적합한 표현 방향:

- 절제된 사건 기록
- 죄책감과 해방감이 함께 남는 문장
- 확정 판정 이후의 정리 문장
- 입력에 있는 사건만 바탕으로 한 요약

피해야 할 표현:

- 원혼을 단순 악당으로 단정
- 입력에 없는 살인, 보상, 랭킹 추가
- 진명을 LLM이 새로 만들어내기
- 승패나 봉인 성공 여부를 LLM이 판단하기
- 공식 설정처럼 새로운 과거사를 덧붙이기

## 현재 프로젝트와의 연결 가능성

현재 승인 문서의 첫 사건은 `거울 속의 손님`이다.

이 데모 시나리오는 아래 요소에서 현재 프로젝트와 잘 맞는다.

- 거울
- 진명
- 기억 상실
- 원혼 또는 괴이의 이름 회복
- 괴이를 죽이는 대신 봉인하거나 해방하는 구조
- 심리 공포와 미스터리 조사 흐름

하지만 아래 항목은 아직 공식 seed 전체로 확장되지 않았다.

- 이안. PDF 초고의 주인공명이며 실제 게임에서는 유저 닉네임으로 대체될 가능성이 높다.
- 엘리자베스. PDF 초고의 원혼명이며 현재 공식 설정에서는 사용하지 않는다.
- 진실의 거울
- 벽 속의 아이들
- 피 묻은 곰 인형
- 원혼의 정확한 과거사

## LLM 사용 경계

이 문서는 LLM이 톤을 참고하는 데 사용할 수 있다.

단, LLM은 이 문서의 내용을 서버 판정이나 공식 스토리 문장처럼 사용하지 않는다.

사용 가능:

- 결과 요약의 분위기 참고
- 심리 공포 톤 참고
- 진명과 해방 중심의 문장 톤 참고

사용 금지:

- 공식 사건명으로 확정
- 공식 진명 조각으로 확정
- 서버 승패나 봉인 판정 근거로 사용
- 프론트 표시 문구로 직접 사용
- 승인 문서 없이 새로운 공식 설정으로 편입

## 후속 확정 필요

- 이 데모 시나리오를 `거울 속의 손님`에 통합할지 여부
- 로그인 유저 닉네임을 주인공명으로 사용할 때 문장 치환 기준
- PDF 초고명 `이안`을 문서와 fixture에서 폐기할지 여부
- 진명 조각 구조와 현재 승인 문서의 3개 조각을 어떻게 맞출지
- 거울이 깨지는 결말을 현재 프로젝트의 봉인 구조와 맞출지 여부
- 프론트 결과 화면에 사용할 공식 문장
- LLM 요약에 허용할 데모 시나리오 참조 범위
