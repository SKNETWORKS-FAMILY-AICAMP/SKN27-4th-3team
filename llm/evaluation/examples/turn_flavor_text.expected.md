# turn_flavor_text 기대 출력 예시

> 이 문서는 LLM 평가용 초안 예시다. 공식 스토리 문장, 서버 판정, 프론트 표시 문구로 사용하지 않는다.

## 입력 fixture

`llm/fixtures/turn_flavor_text.sample.json`

## 정상 출력 예시

```text
낡은 종이 위로 지워진 이름의 흔적이 떠오른다.
거울 안쪽에서, 피티가 조용히 고개를 든다.
```

## 통과 기준

- 서버 공개 로그의 의미를 바꾸지 않는다.
- 입력에 없는 턴 결과나 다음 행동을 만들지 않는다.
- 1~2줄만 출력한다.
- 각 줄은 45자 이하로 유지한다.
