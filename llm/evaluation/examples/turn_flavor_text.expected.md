# turn_flavor_text 기대 출력 예시

> 이 문서는 LLM 평가용 초안 예시다. 공식 스토리 문장, 서버 판정, 프론트 표시 문구로 사용하지 않는다.

## 입력 fixture

`llm/fixtures/turn_flavor_text.sample.json`

## 정상 출력 예시

### insight

```text
낡은 종이 위로 지워진 이름의 흔적이 떠오른다.
거울 안쪽에서, 피티가 조용히 고개를 든다.
```

### ritual

```text
금 간 거울 앞에서 촛불이 낮게 떨린다.
검은 유리 너머로 피티의 그림자가 번진다.
```

### guard

```text
속삭임이 손등을 스치고 어둠 속으로 사라진다.
검은 흔적은 아직 식지 않았다.
```

### silence

```text
침묵이 길어질수록 거울 속 시선이 선명해진다.
피티는 말없이 너를 바라본다.
```

### contract

```text
붉은 글씨가 손끝을 따라 천천히 번진다.
종이 밑에서 낮은 웃음이 울린다.
```

## 통과 기준

- 서버 공개 로그의 의미를 바꾸지 않는다.
- 입력에 없는 턴 결과나 다음 행동을 만들지 않는다.
- 1~2줄만 출력한다.
- 전체 20~90자로 유지한다.
- 각 줄은 45자 이하로 유지한다.
