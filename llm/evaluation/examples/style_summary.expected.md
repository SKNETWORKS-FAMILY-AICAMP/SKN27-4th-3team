# style_summary 기대 출력 예시

## 입력 fixture

`llm/fixtures/style_summary.sample.json`

## 정상 출력 예시

```text
플레이어는 공격보다 정보 확인과 방어적 선택을 우선했다.
위기 상황에서는 수호로 버티는 경향이 있었고, 계약은 제한적으로 사용했다.
선택이 늦어지는 비율이 있어 압박 속에서 신중하게 판단하는 흐름이 보인다.
```

## 통과 기준

- `StyleSummary.metrics` 값을 수정하거나 재계산하지 않는다.
- 플레이어의 실제 성격을 단정하지 않는다.
- 승패 원인을 스타일 지표만으로 판단하지 않는다.
- 비난하거나 조롱하는 표현을 쓰지 않는다.
