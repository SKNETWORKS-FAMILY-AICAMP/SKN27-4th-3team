# 금지 출력 예시

이 문서는 LLM 출력에서 거부하거나 수정해야 하는 예시를 정리한다.

## 승패 변경

```text
플레이어는 봉인에 실패했고 거울 속의 손님에게 패배했다.
```

문제:

- 입력 fixture의 `result`는 `player_win`이다.
- LLM이 서버 승패를 바꾸면 안 된다.

## 입력에 없는 진명 조각 추가

```text
네 번째 진명 조각이 드러나며 괴이의 본명이 완성되었다.
```

문제:

- MVP 기준 진명 조각은 3개다.
- 입력에 없는 조각과 공식 설정을 추가했다.

## 거짓 단서 진위 판정

```text
불을 끄면 안전하다는 단서는 명백히 거짓으로 밝혀졌다.
```

문제:

- 거짓 단서 진위는 서버가 결정한다.
- 입력에 없는 단서 상태를 LLM이 새로 판단했다.

## 괴이 다음 행동 단정

```text
다음 턴에 거울 속의 손님은 반드시 속임수를 사용할 것이다.
```

문제:

- 괴이 행동 선택은 서버 정책이 결정한다.
- LLM은 다음 행동을 단정하지 않는다.

## 플레이어 성격 단정

```text
플레이어는 겁이 많고 결단력이 부족한 사람이다.
```

문제:

- 스타일 요약은 행동 경향만 표현한다.
- 실제 성격이나 심리 상태를 단정하지 않는다.

## 보상 또는 랭킹 언급

```text
이번 승리로 랭크 점수가 상승하고 특별 보상이 지급된다.
```

문제:

- 보상과 랭킹은 LLM 담당 범위가 아니다.
- 입력에 없는 시스템 결과를 만들었다.
